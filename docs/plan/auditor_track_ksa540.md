# 감사인 트랙 구체화 — 기준서 540(회계추정치) 절차 정렬

> 감사」 요구사항(문단 13~39)을 원문에서 파악해, 각 문단을 도구 기능에 매핑하고 갭과
> 구현 순서를 고정한다. 작성 2026-08-01.
> 원문 출처: 감린이 레포 `DB/audit_standards_parsed_preprocessed.md` 540 구간(문단 전문).
> 선행 계획: [model_connectivity_and_recovery.md](model_connectivity_and_recovery.md)

**구조 요지**: 540은 `방법 / 유의적 가정 / 데이터` 3원소를 위험평가(13·16)부터 대응(23·24·25),
독립추정(28), 서면진술(37)까지 **일관되게 반복**한다. 도구의 데이터 모델도 이 3원소를
1급 개념으로 가져야 기준서와 조서가 자연스럽게 정렬된다.

## 2. 재설계 — 감사인 트랙을 540 절차로 정렬

현행 4단계(인제스트→재계산→진단→발견사항)를 540의 뼈대에 맞춰 확장한다.
**설계 원칙**: 도구는 각 문단의 "증거 재료"를 만들고, 판단·결론은 감사인이 내린다.
산출물마다 근거 문단을 태깅한다(조서 39(b)가 공짜로 나오는 구조).

### A1. 추정치 이해·위험평가 (문단 13~16) — 신규 시트 「위험평가」

- **추정치 인벤토리**: 의견서/모델에서 회계추정치 후보 추출(기존 opinion_template 확장).
- **고유위험 스펙트럼 평가**: 추정치별로 3축 판정 — 추정불확실성 / 복잡성 / 주관성.
  - 도구 보조: 민감도 폭(불확실성 프록시), 모델 구조 복잡도(그래프 노드·순환·시트 수),
    가정 중 판단성 항목 비율(주관성 프록시).
  - 판정은 감사인 선택(High/Med/Low) — 도구는 프록시 지표만 제시.
- 산출: 추정치별 `{추정치, 경영진주장, 고유위험 3축, 유의적 위험 여부}` → **이후 모든
  절차·finding 이 이 위험평가에 링크**된다(39(b) 연결 문서화의 축).

### A2. 접근법 선택 (문단 18) — 명시적 분기 UI

세 접근을 **선택하게 만든다**(왜 이 접근인지가 조서 기재사항):
- ① 후속사건(21) → 도구 밖, 체크리스트만
- ② **경영진 방법 테스트(22~27)** → A3
- ③ **독립 점/범위추정(28~29)** → A4
- 18 말미의 **무편향 요구**를 UI 규약으로: 도구는 확인/상반 증거를 구분 표시하고,
  상반 증거를 접거나 숨기는 기능을 두지 않는다(33~34 대비).

### A3. 경영진 방법 테스트 (문단 22~27) — 본 계획의 핵심 신규

**전제**: 값-only 모델 복원(연결성 계획 P2). 복원 후보 + 미해결 목록이 이 단계의 입력.

| 문단 | 도구 기능 | 신규/기존 |
|---|---|---|
| 23(a) 방법 적합성·변경 | 기법 식별(DCF/상대가치/…) + `method_selector` 역방향 대조("이 상황에 이 기법이 적합한가") + 전기 모델 diff | 신규(조합) |
| 23(c) 수학적 정확성 | 복원 스파인 재계산 vs 주장값 + 항등식 검산 + `diagnose_dcf_gap` | 기존 재사용 |
| 23(d) 복잡한 모델 | 의존성 그래프(P0) — 모델 조정(23(d)(ii))은 **오버라이드 탐지**(정상 계산과 다른 상수 주입 지점) | P0 파생 |
| 23(e)·25 데이터 무결성·신뢰성 | **가정↔원천 원장**(연결성 계획 P3): 복원된 가정마다 원천 문서·데이터를 감사인이 연결, 미연결 = 질의사항 | P3 |
| 24(a) 가정 적합성 | 기존 게이트 전량 투입(PGR≥WACC·TV비중·β/MRP·산업 분포 대조·컨센서스 앵커) | 기존 재사용 |
| 24(b)·25(b) 편의 징후 | → A5 편의 대시보드로 집약 | 신규 |
| 24(c) **가정 간 일관성** | **신규 게이트 `check_cross_estimate_consistency`**: 같은 기업의 추정치들이 공유해야 할 가정(성장률·할인율 구성요소·환율·물가) 교차 대조. 예: 손상검사 g 3% vs 평가모델 g 1% → WARN | **신규 (핵심)** |
| 26~27 불확실성 대응 | 민감도·시나리오 유무와 폭 확인 → 없으면 27 캐스케이드 안내(경영진 요구 → 불충분 시 A4로) | 기존+배선 |

### A4. 독립 점/범위추정 (문단 28~29) — 기존 확장

- 점추정: 현행 `IndependentRecalc` 유지.
- **범위추정 신규**: 감사인이 가정별 합리 구간을 입력 → 엔진이 범위 산출.
  - 29(a) 규율을 코드로: **구간의 양끝도 각각 근거 필요**(근거 없는 넓은 범위 금지)
    — 가정별 구간에 출처 필수 입력, 미입력 시 계산 차단(이 레포의 게이트 철학 그대로).
  - 판정: 경영진 점추정치가 감사인 범위 안인가 → 밖이면 **최소 조정액**(범위 경계까지)
    산출 = 450 왜곡표시 집계로 연결.
- 28 후단 규율: 감사인 자신의 방법·가정·데이터도 23~25와 같은 기준 — 독립추정 입력에도
  동일 게이트(provenance·범위 sanity)를 태운다(이미 그렇게 배선돼 있음 — 명문화만).

### A5. 편의 징후·전반 평가 (문단 14·32~36) — 신규 「편의·평가」 시트

- **소급 검토(14)**: 전기 추정 vs 실제 결과 대조표(DART 실적 커넥터 재사용).
  추정오차의 **방향성**(항상 유리한 쪽으로 빗나가는가)을 시계열로 표시.
- **편의 징후(32)**: 개별 게이트는 통과해도 **판단의 방향이 일관되게 한쪽**인지 집계 —
  예: 성장률은 상단, 할인율은 하단, WC 는 낙관 → 개별 PASS 라도 편의 카운터 표시.
  L3 `check_consensus_anchor`(자기추정 vs 컨센서스)도 여기 집약.
- **왜곡표시 3구분(35)**: `impact_ledger` 결과를 감사인이 분류 —
  사실적(계산 오류: gap_diagnosis 적중분) / 판단적(가정 차이) / 투영된 것.
  분류별 합계 → 450 미수정왜곡표시 집계 형식.

### A6. 문서화 (문단 39) — 조서 출력

- finding 마다 이미 있는 것: 규칙·근거 문서·severity·detail. 여기에 **위험평가 링크
  (A1)와 540 문단 태그**를 더하면 39(b) "위험평가 근거 ↔ 절차의 연결"이 자동 충족.
- 출력: 추정치별 조서 마크다운 — ①위험평가(3축) ②선택한 접근과 이유 ③수행 절차와
  결과(finding) ④편의 징후 평가 ⑤합리성 결정(감사인 서술, `report/language_guard`
  린트 적용) ⑥미해결 질의사항.
- 서면진술(37)·커뮤니케이션(38)은 체크리스트 항목으로만(도구 밖 명시).

## 4. 검증

- **범위추정**: 비올 골든에서 가정 구간을 점으로 좁히면 점추정과 일치해야 함(수렴 검증).
- **교차 일관성 게이트**: 합성 픽스처(손상 g≠평가 g) FAIL + 동일 가정 PASS.
- **편의 방향성**: 비올 리뷰노트의 실측 패턴(E-6 원가율 유리한 해 참조, J-1)이
  방향성 카운터에 잡히는지.
- **조서**: 산출 마크다운에 위험평가 링크·문단 태그·미해결 목록이 전부 존재하는지 정적 검사.
