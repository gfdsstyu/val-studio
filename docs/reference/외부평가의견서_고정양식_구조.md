# 외부평가의견서 고정 양식 — 고정부 vs 가변부

> **핵심 원리**: 외부평가기관(Big4 등)의 평가의견서는 **양식이 고정적**이다. 회사·거래마다
> 바뀌는 것은 *데이터(가변부)*이고, 방법론 골격·섹션 구조·정형 문구(고정부)는 동일하다.
> 이 분리가 (1)파서의 결정론적 앵커링 (2)LLM의 구조 이해 (3)우리 의견서 자동생성의 토대.
>
> 근거: DART 공시 외부평가의견서 13건 교차비교(다산·아모레퍼시픽·청호ICT 등). 한글 라벨이
> CID폰트로 깨져도 **방법론 앵커(WACC·Hamada·Bloomberg·Re-levered Beta·Terminal·DCF)가
> 모든 의견서에 동일 등장** → 고정 골격 실증.

---

## 1. 고정부 (안 달라지는 부분 — skeleton)

### 1-A. 섹션 골격 (목차 구조)
```
1. 평가의 개요            (평가목적·기준일·대상·의뢰인)
2. 평가기관의 독립성·적격성
3. 평가대상회사 개요
4. 평가
   4.x 평가방법의 선정 (DCF법 등)
   4.x.1 현금흐름 추정 (매출·원가·판관비·법인세·CAPEX·WC → FCF)
   4.x.1.6 할인율(WACC) 산정
   4.x.1.7 영구성장률
   4.x.2~ (종속회사별 반복 — SOTP)
   4.x.최종 평가결과 (영업가치→비영업자산→기업가치→이자부부채→지분가치)
5. 평가의견
+ 부속명세: 민감도, 유사회사, 재무제표
```

### 1-B. 방법론 골격 (모든 의견서 동일)
| 요소 | 고정 방법 |
|---|---|
| 평가법 | **DCF법**(비상장 타법인주식양수 지배적) — [[외부평가의견서_활용]] |
| WACC | `WACC = Ke·E/V + Kd·(1−Tc)·D/V` (문자식 고정) |
| Ke | Modified CAPM: `Rf + β·MRP + Size Premium` |
| Beta | **Hamada** Un-lever→Re-lever, guideline peer(GICS 업종), Bloomberg 2yr Weekly Adjusted |
| Rf | Bloomberg (10년 국고채류) |
| 영구성장률 | **1.00%** (한국 보수 관행, 실측 다산 5개체·청호·애니플러스 전부 1.00%) |
| 브리지 | 영업가치 → +비영업자산 → 기업가치 → −이자부부채 → 지분가치 |

### 1-C. 정형 문구 (boilerplate)
독립성·적격성 선언, 준거기준(자본시장법·외부평가 가이드라인), 평가의 한계·유의사항,
이용제한·면책 — 거의 동일 반복. → [[외부평가의견서_활용]] §4 정형문구 상수.

## 2. 가변부 (달라지는 부분 — slot)

| 슬롯 | 변동 요인 | 예시 |
|---|---|---|
| 대상회사·거래 | 딜마다 | 다산네트웍솔루션즈 / 코스알엑스 |
| **엔티티 수(SOTP)** | 단일 vs 다개체 | 다산=5개체(DNS+DZS Japan/Vietnam/D-Mobile/India) |
| **통화** | 해외 종속시 | JPY·VND·USD → 기준통화 환산([[검증_클래시스_DCF]] 옆 `sotp.py`) |
| peer set | 업종(GICS)별 | Communications Equipment: ZTE·Fiberhome… |
| WACC 값 | 회사·시점별 | 다산 DNS 12.80% |
| Size premium | 규모(Micro/Small…) | DNS Micro-Cap 3.35% |
| 추정 재무수치 | 전부 | 매출·원가·FCF·EV·지분가치 |
| 영구성장률 값 | 대부분 1% (드물게 상이) | 1.00% |

## 3. 활용 — 세 소비자

### ① 파서 (결정론적 앵커링)
블라인드 표 탐지 대신, **고정 앵커(WACC 문자식·"Re-levered Beta"·"Terminal"·섹션번호)로
가변 데이터를 위치 특정**. 한글 라벨이 깨져도 영문·수식 앵커는 생존 → `pdf.py`가 앵커 주변
표를 우선 추출. (향후 `parsers/opinion_template.py`: 섹션맵 기반 필드 추출.)

### ② LLM RAG (구조 이해)
LLM이 "이 의견서의 WACC는?"에 답할 때, 고정 섹션 구조를 알면 4.x.1.6 근처만 보면 됨.
가변부만 추출해 답변 → 정확도↑. 사업보고서도 동일(고정 목차 활용, 자료 확보 시 추가).

### ③ 우리 의견서 자동생성 (report)
고정 골격(§1) = 우리 report 템플릿의 skeleton. 가변부(§2) = `calc_core`·가정 슬롯 치환.
→ 우리가 생성하는 평가의견서가 실제 공시 양식과 동형.

  평가결과를 앵커 기반 결정론 추출(블라인드 표탐지 보완).

- **사업보고서**: 자료 확보 시 동일 고정양식 분석(목차·재무제표·주석 위치) 추가.
