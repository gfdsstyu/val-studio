# 마진·원가 드라이버 타이폴로지

FCFF의 시작 **NOPAT = EBIT × (1−t) = (매출 − 매출원가 − 판관비) × (1−t)**. 매출
([[매출추정_논리_타이폴로지]])이 정해지면, **매출→이익 전환**이 마진 드라이버. 매출이 "P×Q",
CAPEX가 "유지+신규"였다면, **마진 = 비용을 성격별로 분해, "변동은 매출연동·고정은 물가·인건비는
연봉·상각은 CAPEX연동"**이 갈림길. 골든=[[계정분류_모델아키텍처]]·[[리포트예시_클래시스]]·
[[FDD_재무실사_정상화]]·[[모델러스_통합모델_5.4]], 실전=SMIC.

## 핵심 공식
```
EBIT = 매출 − 매출원가 − 판관비
매출원가율(%) = 매출원가 / 매출 ;  판관비율(%) = 판관비 / 매출 ;  OPM(%) = EBIT / 매출
성격별:  변동비 = 매출 × 변동비율     고정비 = 전기 × 물가상승
        인건비 = 인원 × 연봉(상승률)  상각비 = CAPEX 롤포워드(→ [[CAPEX_드라이버_타이폴로지]])
```
→ [[가정원장_방법론]] 자기정합성 검산: `영업이익 ≟ 매출 × (1 − 원가율 − 판관비율)`.

## 드라이버 아키타입

| # | 방식 | 정의 | 출처 |
|---|---|---|---|
| M1 | **% of Sales (율 고정)** | 매출원가율·판관비율을 매출에 연동 | 모델러스·계정분류 |
| M2 | **성격별 분해** | 변동/고정/인건/상각 분리 추정(정석) | 클래시스·계정분류 |
| M3 | **목표/peer OPM** | 영업이익률을 목표·peer·과거평균으로 | 현대차·peer |
| M4 | **원재료 연동(스프레드)** | 원가를 원재료 가격에 연동 | 정유·철강(S-Oil) |
| M5 | **정상화(normalized)** | 일회성 제거한 정상 마진(QOE) | FDD 실사 |

### M1. % of Sales (율 고정)
매출원가율·판관비율을 일정 비율로 고정(모델러스 `판관비 = 매출 × %`, 매출원가 = 잔차 또는 율).
빠르나 **operating leverage**(고정비 레버리지)를 못 담음 — 매출 늘어도 마진 불변으로 과소·과대.

### M2. 성격별 분해 (정석)
비용을 **변동비(매출연동)·고정비(물가·고정)·인건비(인원×연봉상승률)·상각비(CAPEX연동)**로 분해
(계정분류·클래시스). 케이씨 "인건비=국내 평균 연봉 상승률, 감가상각=5개년 평균 유형자산".
→ 매출 성장 시 고정비 레버리지로 **OPM 자동 개선**을 포착. 가장 견고.

### M3. 목표/peer OPM
영업이익률을 목표·peer·과거평균으로 고정하고 역산. 현대차 "OPM 9.2%". 단순하나 근거(왜 이 마진?)가
약하면 자의적. 믹스 개선 스토리(고가 라인업)와 연결해야.

### M4. 원재료 연동 (스프레드)
원가를 원재료 가격에 직접 연동. 정유·석화·철강 = **판가-원료 스프레드**([[매출추정_논리_타이폴로지]]
추가관찰). S-Oil 정제마진, 세아제강 롤마진. 마진 변동성이 원재료에 지배.

### M5. 정상화 (normalized)
일회성·비경상 항목을 제거한 **정상 마진**([[FDD_재무실사_정상화]] QOE). M&A·실사에서 EBITDA
정상화 → 가치평가·가격조정. 계절성·재고평가손익 등 조정.

## 교차 관찰 (4대 드라이버 완성)
1. **비용 = 성격별 분해가 정석**, 차이는 "각 성격을 무엇에 연동"(변동=매출 / 고정=물가 / 인건=연봉
   / 상각=CAPEX). % of sales(M1)는 단순형이나 operating leverage를 놓친다.
2. **OPM은 결과이자 입력** — M3은 OPM을 직접 두고 역산, M2는 비용에서 OPM이 창발. 성장 스토리엔
   M2(레버리지 포착)가 맞다.
3. **상각비는 CAPEX와 순환** — 상각비 = CAPEX 롤포워드([[CAPEX_드라이버_타이폴로지]] X5)로 연결.
4. **자기정합성 검산**: `영업이익 ≟ 매출 × (1−원가율−판관비율)`이 자기 표와 맞는가([[가정원장_방법론]]).

## FCFF 4대 드라이버 지도
```
매출(P×Q)      → [[매출추정_논리_타이폴로지]]      A~K
  ↓ ×마진
NOPAT          → 이 문서(마진·원가)               M1~M5
  ± D&A/CAPEX  → [[CAPEX_드라이버_타이폴로지]]     X1~X5
  − ΔNWC       → [[운전자본_드라이버_타이폴로지]]  W1~W5
= FCFF
```

## 활용
- 플랫폼 마진 라우터(M1~M5) + 성격별 분해 + operating leverage + 정상화 게이트.
- 마진 벤치마크: 산업별 영업이익률·원가율·판관비율([[벤치마크_마진]]).
- 가정 원장 자기정합성 검산.
