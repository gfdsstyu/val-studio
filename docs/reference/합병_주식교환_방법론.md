# 합병·주식교환 평가 방법론 (두산 사례)

출처: `MSVALUE강의자료\(MSVALUE) 특강_두산 합병.xlsx`. DCF와 **다른 규제 트랙**의 평가.
두산로보틱스(완전모회사) ↔ 두산밥캣(완전자회사) 포괄적 주식교환 사례.

---

## 1. 상장법인 합병·주식교환가액 = 자본시장법 기준주가

자본시장법 시행령: **상장법인**은 **기준주가**로 산정 (본질가치/DCF 아님).
```
기준주가 = 산술평균(
  ① 최근 1개월 거래량가중산술평균종가,
  ② 최근 1주일 거래량가중산술평균종가,
  ③ 최근일 종가 )
```

### 두산 사례 (기준일 2024.07.10)
| | 1개월 VWAP | 1주일 VWAP | 최근일 종가 | **산술평균=교환가액** |
|---|--:|--:|--:|--:|
| 두산로보틱스(모) | 82,859 | 77,482 | 80,000 | **80,114원** |
| 두산밥캣(자) | 50,543 | 50,292 | 51,000 | **50,612원** |

- **주식교환비율** = 50,612 / 80,114 ≈ 0.6318 (밥캣 1주 → 로보틱스 0.63주).
- 참고: 지분가치(시총)·순자산장부가 병기해 검토.
  - 로보틱스: 발행주식 64,819,980, 지분가치 5.19조, 순자산 0.44조
  - 밥캣: 100,092,209주, 지분가치 5.07조, 순자산 6.00조

## 2. 비상장법인 = 본질가치 (자본시장법)
```
본질가치 = (자산가치 × 1 + 수익가치 × 1.5) / 2.5
  자산가치 = 순자산 공정가치 / 발행주식수
  수익가치 = 향후 추정이익 기반(DCF/이익할인)
```
- DCF는 **수익가치 산정** 또는 **본질가치 검토·보완**에 사용.
- 외부평가의견서(비상장 대상)에서 DCF법이 지배적인 이유(§외부평가의견서 taxonomy).

## 3. 방법론 트랙 비교

| 상황 | 평가방법 | 근거 |
|---|---|---|
| 상장사 합병·주식교환 | 기준주가(시장가) | 자본시장법 시행령 |
| 비상장사 합병 | 본질가치(자산 1 : 수익 1.5) | 자본시장법 시행령 |
| 비상장 타법인주식양수 | **DCF법** (외부평가) | 외부평가업무 가이드라인 |
| 자산성/옵션성 | 조정순자산·시장접근·이항모형 병행 | 대상 성격 |

> 우리 플랫폼: DCF가 코어(`calc_core`). 합병/주식교환은 **기준주가·본질가치 모듈**로 확장(시장가 크롤=price_client, 본질가치=순자산+수익가치 가중). 두산 사례의 DCF·DCF(로보틱스) 시트는 수익가치 교차검증용.

## 4. 시사점
- **합병 = DCF와 별개 규제 산식**(기준주가/본질가치)이나 DCF로 타당성 검토.
- 주식교환비율은 감사인·소액주주 분쟁 소지 큼 → 다중 방법 교차·민감도 필수.
- report 템플릿: 거래유형(합병/양수도/주식교환) → 방법론 자동 선택(§외부평가의견서 §4).
