# SMIC 기업 밸류에이션 리포트 코퍼스

**소스 위치**: `D:\Valuation\SMIC\` (~150편) + `C:\smic_reports\` (추가 ~29편, 2019~2021
초기 회차·해외기업 Alibaba/VISA/Equinix 등 포함). 전체 배치(P3) 시 두 경로 병합 대상.

`D:\Valuation\SMIC\` = 가치투자 학회의 2015~2026 기업 밸류에이션 리포트 ~150편(팀 산출물).
각 편은 **산업분석 → 투자포인트 → 부문별 매출추정 → SOTP/멀티플 밸류에이션 → 목표주가**의
정형 구조. 이 코퍼스는 두 가지 지식을 준다:

1. **산업→기업 매출추정 논리** — 산업마다 매출을 무슨 동인으로 세우는지의 실증 →
   [[매출추정_논리_타이폴로지]]로 귀납.
2. **SOTP/멀티플 실무** — 사업부·자회사를 어떤 peer 배수로 평가하는지의 사례.

> ⚠️ **rigor = 학회리포트**. 비올·클래시스·[[모델러스_통합모델_5.4]] 같은 *권위 골든*(→
> `checks.py` 규칙 승격)과 **등급이 다르다**. 편차가 크고 낙관 편향이 관측된다. 여기서는
> **패턴/벤치마크 참고 코퍼스**로만 쓰고, 개별 수치를 규칙으로 승격하지 않는다.
>
> ⚠️ **원본 비배포**: 학회 산출물. 전문 텍스트는 개인 RAG용으로 `smic/_fulltext/`에만
> 보관, 레포 재배포 대상 아님([[참고보고서_활용]]와 동일 원칙).

## 인제스트 파이프라인 (텍스트 우선)
`scripts/smic_ingest.py` — PyMuPDF `get_text()`로 전문 추출(텍스트형 PDF는 무료·고속).
- 산출: `smic/_fulltext/<slug>.md`(전문), `smic/_extract/<slug>.json`(구조화 스텁),
  `<slug>.excerpt.md`(매출추정·밸류 발췌).
- **자동으로 잘 되는 것**: 전문·목표주가·기법(SOTP vs 멀티플)·매출추정 서술.
- **vision/큐레이션 필요**: **peer 배수 표** — get_text()가 표 그리드를 선형화하며 peer
  *이름*이 파편화(값은 정확). 재무모델 그리드도 동일. → 후속 vision 보강 또는 수기 큐레이션.

### P2 결과 — peer 표 vision 보강 (`scripts/smic_peer_vision.py`)
peer-table 페이지만 선별 → 2x 렌더 → Gemini 2.5 Flash vision. **검증**: 케이씨에서
`{케이씨인더스트리얼, 원익머트리얼즈, EV/EBITDA, 3.26, p23}`을 이름·세그먼트·값 완벽 추출.
**한계 발견**: 학회 리포트는 peer를 **자회사별 산문에 분산** 기재 → 단일 표 vision은 일부만
포착(케이씨 4개 중 1개). 반면 **원문 텍스트는 값을 더 많이 포착**(깨진 건 표의 peer *이름*뿐).
→ **결론: 값=텍스트/vision, 이름·세그먼트=산문 큐레이션의 하이브리드**가 최적. 순수 target
멀티플 방식(하이브 PER, 오리온 PER)은 컴프스 표가 없어 vision `[]`가 정상.

## 온톨로지 편입 메모
`ontology/build.py`는 `docs/reference/*.md`를 **top-level만** glob → 개별 리포트(`smic/`
하위)는 자동 미포함. 대표로 **이 인덱스 + [[매출추정_논리_타이폴로지]]** 2편이 온톨로지
그래프에 SMIC를 표상한다. 개별 편까지 그래프에 넣으려면 build.py를 `rglob("smic/*.md")`로
확장(후속 결정).
