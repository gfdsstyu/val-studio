# 장표 작성법 — 리포트 단계의 산출물 규율

> 출처: 컨설팅 실무 교육 문서(Slide Writing). [[모델링_워크플로우_기초]] 업무 프로세스
> 8단계의 종착("장표 작성") 상세 — 우리 리포트 단계(5)·평가의견서 생성의 표현 규율.

## 1. 장표의 지위와 구조
**프로젝트의 모든 작업은 장표 작성으로 귀결된다.** 장표 한 장 = 핵심 메시지 결정 →
근거 마련 → 보기·듣기 쉽게 표현.
- 구성: **Head**(메시지) + **Body**(백업) — Body = Text(상세정보) · Chart(정량 데이터) ·
  Diagram(구조·로직)의 조합.

## 2. 좋은 장표의 4 기준
① **메시지가 명확** — 이 장으로 전달할 한 문장이 있는가, 앞뒤 장표와 흐름이 자연스러운가
② **부연 설명 불요** — 핵심을 즉독 가능한가(Reader Friendly)
③ **구조가 탄탄** — 리서치·분석이 완전한가, 문장이 논리적인가
④ **아름다움** — 전 장표 통일 구성 + 심미성.

## 3. 작성 원칙
- **'메시지'를 먼저 도출하라** — 메시지가 구성을 결정([[모델링_워크플로우_기초]]의
  "산출물 먼저 구상 후 엑셀" 원칙과 동형).
- **축을 활용해 MECE 하게** — 매트릭스 구조로 완성도·가독성. 대표 축:
  - 밸류체인: R&D > 생산 > 마케팅 > 영업 > A/S
  - Value driver 분해: 영업이익 = 매출 − 비용 / 매출 = P × Q / 비용 = COGS + SG&A
- **Leveling**(bullet 위계로 강조·가독) · 손으로 먼저 그려보기 · 최적 차트 선택 ·
  전체 보고서 내 이 장표의 '목적'(앞뒤 장 맥락) 확인 후 작성.

## 4. 차트 선택 정본 ⭐ (데이터 성격 → 차트)
| 차트 | 언제 |
|---|---|
| **Stacked bar** | 구성 + 성장성을 함께 |
| **100% stacked bar** | M/S 등 비중의 변화 |
| **Combination**(막대+선) | 절대값과 비율을 함께 |
| **Line** | 2개 이상 시계열 |
| **Waterfall** | 증분/감소분의 크기(가치 브리지 — EV→Equity, 가정 변경 효과) |
| **Mekko** | 비중과 규모를 동시에 |
| **Scatter** | 두 축 상관관계 |
| **Bubble** | 상관관계 + magnitude |

## 우리 플랫폼 매핑
- 리포트/평가의견서 생성(5단계) 프롬프트에 "Head 메시지 1문장 먼저 → Body 근거" 순서를
  강제 — LLM 서술이 스토리라인-숫자 alignment 를 지키게.
- 밸류에이션 브리지(EV→지분가치) 시각화 = Waterfall, 민감도 = 매트릭스, 세그먼트
  매출 구성 = Stacked bar, peer 배수 비교 = Scatter/Bubble — 프론트 차트 컴포넌트
  선택 기준으로 그대로 사용.
- MECE 축 두 정본(밸류체인·value driver 분해)은 Brief ⑥과 계정분류(타사)의 서술 골격.
