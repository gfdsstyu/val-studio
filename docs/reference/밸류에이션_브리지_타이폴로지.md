# 밸류에이션 브리지 (EV → 목표주가)

드라이버(매출·마진·CAPEX·WC)로 FCFF·영업가치를 세우거나 배수로 EV를 뽑은 뒤, **목표주가까지
가는 조정 사슬**이 브리지다. 이 단계에서 실수(비지배지분 누락·이중계상)가 잦아 감사 red flag가
많다. SMIC SOTP·지주 리포트의 (A)~(E) 구조를 귀납. 골든=[[리포트예시_클래시스]]·
[[외부평가의견서_고정양식_구조]].

## 표준 브리지 (에프앤에프홀딩스 (A)~(E) 정본)
```
(A) 상장/핵심 영업가치      Σ 사업부·자회사 SOTP (배수 또는 DCF)
(B) 비상장/기타 영업가치    + 나머지 부문
(C) 영업가치 = A + B
(D) 비영업가치             + 투자자산·부동산·순현금 (영업 외)
(E) 순차입금(net debt)     − 총차입 − 현금
(F) 비지배지분(소수주주)    − 연결 자회사 소수주주 몫
(G) 지주/NAV 할인          × (1 − 할인율)   [지주사만]
= 지분가치(equity value)
÷ 주식수(자기주식 제외·희석 반영)
= 목표주가
```

## 조정 단계 (B-노드)

| # | 조정 | 정의 | 함정 |
|---|---|---|---|
| Br1 | **영업가치 SOTP 합산** | 부문·자회사별 가치 합 | 부문 이중계상 |
| Br2 | **비영업가치 가산** | 투자자산·부동산·순현금 | 지분법 자회사를 SOTP+투자자산 이중계상 |
| Br3 | **순차입금 차감** | 총차입 − 현금성 | 리스부채·우발부채 누락 |
| Br4 | **비지배지분 차감** | 연결 자회사 소수주주 몫 | **누락 시 지분가치 과대** (최빈 오류) |
| Br5 | **지주/NAV 할인** | 지주사 할인율 적용 | 할인율 자의성(두산 NAV 할인) |
| Br6 | **주식수 나눗셈** | 자기주식 제외·희석 반영 | 자기주식·CB 희석 처리 오류 |

## 각 조정
- **Br1 영업가치**: SOTP면 부문별 배수·DCF 합(케이씨 핵심+자회사 영업가치, 에프앤에프 상장/비상장).
- **Br2 비영업가치**: 영업과 무관한 투자자산·부동산·순현금 가산. **⚠️ 지분법 자회사를 영업가치
  SOTP에 넣었다면 투자자산에 또 넣으면 이중계상.**
- **Br3 순차입금**: EV는 부채 포함 개념 → 지분가치로 오려면 순차입금 차감(한화솔루션·에프앤에프 (E)).
- **Br4 비지배지분**: 연결 자회사를 100% 반영한 영업가치에서 **소수주주 몫을 빼야** 지배주주
  지분가치. **누락이 가장 흔한 오류**(비지배지분·비지배지분의 변동, 한화솔루션·한화에어로).
- **Br5 지주/NAV 할인**: 지주사는 자회사 가치 합보다 할인 거래(두산 "높은 NAV 할인율") — 할인율
  근거(유동성·이중과세·지배구조)를 명시해야.
- **Br6 주식수**: 자기주식 제외, CB/BW·스톡옵션 희석 반영(한화솔루션 발행주식 수·자기주식 처분).

## 교차 관찰 (감사 게이트)
1. **비지배지분 누락 = 최빈 과대평가 오류.** 연결 SOTP는 반드시 소수주주 차감.
2. **이중계상 3종**: (a) 지분법 자회사 SOTP+투자자산, (b) 순현금과 비영업 현금, (c) 부문 경계 중복.
3. **지주 할인은 근거 필수** — 안 하면 자의적 상·하향의 조정 노브가 됨([[가정원장_방법론]] provenance).
4. **자기정합성**: 목표 시가총액 ÷ 주식수 = 목표주가가 맞는가([[가정원장_방법론]] 검산).

## 활용
- 플랫폼: 영업가치 → 브리지 체크리스트(Br1~Br6) 자동 적용 + 비지배지분·이중계상 경고.
- 브리지 누락/할인 근거 미명시 = 감사 트랙 red flag.
