## 2. audit-xls — 모델 감사 체크리스트 정본 ⭐ (감사인 트랙 직결)

**스코프 3단**(selection/sheet/model) + 심각도 3단(Critical/Warning/Info) 보고표.
"**BS 안 맞으면 그것부터** — 나머지는 전부 의심", "**하드코딩 오버라이드가 조용한
버그 1위** — 공격적으로 수색".

- 수식 레벨: 에러(#REF! 등)·**수식 내 하드코딩(=A1*1.05)**·이웃 패턴 깨는 수식·
  off-by-one 범위·**수식이었다가 값으로 덮인 셀**·순환참조·깨진 크로스시트 링크·
  단위 혼재·숨은 행/탭.
- 무결성(모델 스코프): BS balance(전 기간)·RE rollforward·**cash tie-out**(CF 기말
  =BS 현금)·D&A(CF=IS)·CapEx(CF=PP&E 롤포워드)·세금=세전이익×세율·주식수=희석 스케줄.
  → 우리 validators ④정합성(주석↔재무제표)과 동족 — 모델 내부 tie-out 판.
- 논리: 성장률>100% 무설명·마진 업계 밖·TV>75%·하키스틱·엣지(0%·음수 EBITDA에서 파손).
- **DCF 특화 버그 목록**: mid-year 오적용·TV 미할인·WACC 장부가 사용·FCF 에 이자
  포함(unlevered 위반)·tax shield 이중계상 — 감사인 트랙 자동검사 후보 5종.
- LBO 특화(⏳미래 트랙 참고): cash sweep↔상환 불일치·PIK 미가산·exit multiple 을
  잘못된 EBITDA(LTM vs NTM)에 적용·Day1 수수료 누락.

## 3. comps-analysis — 상대가치 트랙 설계 참고 (⏳)

- **"5-10 Rule"**: peer 5~10개(우리 4-step 산출 6사와 정합).
- 데이터 소스 우선순위 명시 + 통계 블록(Mean/Median/Min/Max — median 우선).
- Cross-Reference Rule: 멀티플 시트는 운영지표 시트를 참조(중복 입력 금지 — SSOT).
- "무슨 질문에 답하나"로 지표 선택(성장주=EV/Rev, 성숙=P/E·EV/EBITDA…) + 업종별 표.

## 4. finance 플러그인 8종(회계결산) — 이식 가치 3건

- **variance-analysis** ⭐: Price/Volume·Rate/Mix 분해(우리 P×Q 와 동형) + 조사
  우선순위(절대액>%>방향의외>신규>누적) + **서사 규격**: `[항목]: [유/불리] $X (Y%)
  / Driver: 왜 / Outlook: 지속·일회성 / Action: 없음·모니터·조사`. 안티패턴 목록
  ("higher than expected" 순환설명·"timing" 무설명·"various small items" 금지)
  → **감사인 리포트·gap 설명 서사 규격으로 채택**.
- **reconciliation**: 차이 항목 3분류 — ①Timing(정상, 자연해소) ②Adjustment(조정
  분개 필요) ③Investigation(원인불명) + aging·에스컬레이션 임계 → validators fail
  의 후속 분류 체계로 채택 후보.
- **audit-support**: 샘플링 4방법(random/targeted/haphazard/systematic)·assertion
  별 계정 매핑 — 재무제표감사 영역이라 우리 스코프 밖(평가 검증), 참고만.

## 5. 종합: 즉시 채택 목록
1. 민감도 **중심셀=base 검증**(결정론) ② 수식 내 하드코딩 감지(workbook_diff)
2. DCF 특화 버그 5종 → 감사인 트랙 체크 ④ variance 서사 규격 → 리포트 프롬프트
3. 단계별 유저 confirm → SKILL 워크플로우 명문화 ⑥ TV 경고 75% 하향 검토.
