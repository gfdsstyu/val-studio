## 읽는 법
- **저마진+짧은DSO** = 대형 전방/B2C(조선·완성차). **고마진+asset-light** = SW/서비스.
- **고CAPEX/S** = 자본집약(반도체·데이터센터). **긴 DIO** = 재고 많은 제조·유통.
- 지배 아키타입([[매출추정_논리_타이폴로지]]) + 대표 기법([[밸류에이션_기법선택_로직]])이 사업모델 요약.
