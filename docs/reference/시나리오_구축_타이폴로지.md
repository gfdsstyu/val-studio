# 시나리오 구축 타이폴로지 (Bull/Base/Bear)

밸류에이션은 점추정이 아니라 range다. **시나리오 = "어느 입력을 흔드느냐"의 선택.** Base(보수적
기준선)를 중심으로 Bull(낙관)·Bear(비관)를 어떤 축으로 벌리는지가 리포트의 논리 품질. SMIC
다수가 3-case를 쓰며, 흔드는 축이 사업 성격을 드러낸다.

## 시나리오 축 아키타입

| # | 흔드는 축 | 정의 | SMIC 실례 |
|---|---|---|---|
| S1 | **물량·P×Q** | 수요·출하량·판가의 낙관/보수 | [[smic/한화오션_20241\|한화오션]](상선 P·Q), [[smic/한화에어로스페이스_20251\|한화에어로]](수주 포대 수) |
| S2 | **마진 밴드** | 영업이익률 밴드 상단/하단 | [[smic/한화솔루션_20251\|한화솔루션]](마진율 밴드 상단 10%) |
| S3 | **Target Multiple** | peer 배수의 국면별 상·하단 | [[smic/크래프톤_20242\|크래프톤]](PER), [[smic/한화오션_20241\|한화오션]](Target Mult), 한화솔루션(First Solar 국면별) |
| S4 | **점유율·침투** | 침투 속도·점유율 경로 낙관/보수 | 시밀러·신재생(E 아키타입) |
| S5 | **거시·사이클** | 수급 국면·거시 변수(셀 쇼티지 등) | 한화솔루션(셀 쇼티지), 메모리 사이클(SK하이닉스) |

## 각 축
- **S1 물량**: 가장 흔한 축. 수요·물량·판가를 낙관/보수로. 한화오션 "상선 P와 Q 동반 견조"(Bull) vs
  보수(Base). 한화에어로 수주 포대 수(보수적으로 사우디 10개 flat).
- **S2 마진 밴드**: 과거 마진율 밴드의 상단/하단을 시나리오로. 한화솔루션 "마진율 밴드 상단 10%
  적용". → [[마진_원가_드라이버_타이폴로지]] operating leverage와 연결.
- **S3 Target Multiple**: exit 배수를 국면별로. 크래프톤 1yr avg PER, 한화솔루션 First Solar의
  호황기(3Q22)/저점(3Q23) 배수를 Bull/Bear에 대응. → [[벤치마크_분포]] 배수 분포.
- **S4 점유율·침투**: 시밀러·신재생은 침투 S-curve 속도로 시나리오(E 아키타입).
- **S5 거시·사이클**: 셀 쇼티지·메모리 사이클 등 수급 국면.

## ⚠️ 교차 관찰 — range 이중계상 함정
1. **운영가정과 exit 배수를 같은 방향으로 동시에 흔들면 range가 이중 팽창**한다. Bull에서 매출·
   마진↑ *그리고* 목표배수↑를 겹치면 낙관이 곱해져 과장된 상단. → 한쪽만 흔들거나, 흔든다면
   상관관계를 명시(고성장이 고배수를 정당화하는 논리). cf. [[모델러스_통합모델_5.4]] 반면교사.
2. **Base는 "보수적 기준선"이어야** — Base가 이미 낙관이면 3-case가 전부 상방 편향.
3. **흔드는 축 = 핵심 불확실성** — 물량이 불확실하면 S1, 마진이면 S2, 밸류에이션이면 S3.
   축 선택 자체가 "무엇이 이 주식의 스윙 팩터인가"의 답.
4. **자기정합성**: 시나리오별 숫자가 각 case의 formula와 맞는가([[가정원장_방법론]] 검산을
   case별로).

## 활용
- 플랫폼: 사업 성격 → 핵심 불확실성 축(S1~S5) 자동 제안 + 이중계상 경고.
- 시나리오 range의 폭·비대칭이 리스크 프로파일 신호.
