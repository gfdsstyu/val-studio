# 엔진 검증 — 클래시스 DCF (2차 실사례)

대상: `pe양식/DCF_클래시스_1ㅁ2ㅁ3ㅁ.xlsx` (복호화 pw=`1a2a3a`, ㅁ→동일위치 영문키).
비올(1차 골든)에 이은 **2차 실사례 교차검증**. 목적: 엔진 재현성 + 개선점 파악.

## 소스 요약
- 클래시스(에스테틱 의료기기), 유진투자증권 컨센서스 인용. 추정 2024F~2028F(5년).
- WACC **6.239%**, PGR(Growth) **5.0%**(⚠️ 한국 관행 0~1% 대비 공격적), 주식수 63,999,519.
- 원본 결과: EV 2,498,000 백만원, 주당 **40,600원**(현재가 48,850, upside −16.9%).

## 검증 결과

### ✅ EBIT 스파인 = 완전 일치 (Δ0)
rev−cogs−sga 로 우리 엔진이 계산한 EBIT이 원본과 백만원 단위 일치(반올림 Δ≤12).
→ Layer A 매출·원가·판관비 로직 **정상**(비올에 이어 2번째 실사례 확증).

### ⚠️ 세금: 방식 근본 차이 → FCF 괴리
| | 우리 엔진 | 클래시스 원본 |
|---|---|---|
| 세금 기준 | **구간세율 × EBIT** | 분석가 입력(법인세차감전순이익 기반, 금융·기타수익 포함) |
| 유효세율 추이 | ~22.9% 평탄 | 23.1% → **15.6%** (2026~ 세액 37,900 고정) |
- 원본은 세금을 **절대액 고정**(성장에도 세금 불변) → 유효세율 하락. 우리는 EBIT 비례.
- 결과 FCF 괴리: y4 우리 180,872 vs 원본 198,700 (Δ−17,828, 세금 과대).

### ✗ 터미널: 5배 폭발 (최대 발견)
| | 우리 엔진 | 클래시스 원본 |
|---|---|---|
| terminal FCF | 196,861 (성장시킨 last NOPLAT) | **31,557** (정규화, 1/6) |
| TV 비중 | **95.7%** | 77.7% |
| EV | 12,640,677 | 2,498,000 |
| 주당가치 | **199,075원** | 40,600원 |
- WACC(6.24%) ≈ g(5%), 스프레드 1.24% → 순진한 Gordon은 TV가 EV의 96%로 폭발, 실제가의 4배.
- 원본 분석가는 terminal FCF를 마지막 명시 FCF(198,700)가 아닌 **31,557로 정규화**해 길들임(재투자·정상화 반영으로 추정).

### ✅ checks.py 게이트 — 위험 정확히 포착
클래시스 입력에 `audit_dcf` 실행 → **3연속 WARN**:
```
⚠ pgr_vs_gdp            PGR 5% > GDP 2% — 영구 경제추월 비현실
⚠ terminal_reinvestment PGR 5% > 2% 재투자 미반영 — TV 과대계상
⚠ tv_weight             TV 비중 95.7% > 90% — 영구가치 과다편중
```
→ 지식→검증 승격이 **실사례에서 작동 증명**. 감사인이 "이 모델은 터미널 공격적" 즉시 인지.

## 개선 가능점 (우선순위)

### A. 세금 주입 지원 (HIGH) — ✅ 구현 완료
`DcfSpineInput`에 `tax_override: list[float] | None` + `effective_tax_rate` 추가.
우선순위 `tax_override > effective_tax_rate > corporate_tax(EBIT)`. 터미널은 마지막
유효세율을 성장 EBIT에 적용. → 클래시스 명시세금(27,100~37,900) 그대로 주입, FCF 일치.

### B. 터미널 정규화 노브 (HIGH) — ✅ 구현 완료
`terminal_fcff_override`(정규화 FCF 직접 주입) + `terminal_reinvestment_rate`(NOPLAT_T×(1−g/ROIC))
추가. 우선순위 `override > reinvestment_rate > D&A=CAPEX 기본`. → 클래시스 31,557 주입으로
TV비중 77.6% 재현. **결과: 클래시스가 3차 골든**(`tests/golden/test_classys_spine.py`, 주당 40,600원 정확 일치).

### C. WACC≈g 가드레일 강화 (MEDIUM)
스프레드 1.24%는 위험. `check_terminal_value_weight`(>90%)·narrow-spread(<1%) 외에,
스프레드 1~2%p 구간도 "고민감" 표기 고려.

### D. 세금-FCF 정합 교차검사 (감사인 트랙, MEDIUM)
원본은 금융·기타수익에 과세하면서 FCF엔 미포함 → 내부 비정합. 우리 auditor 트랙이
"과세표준 ≠ FCF 구성"을 tie-out으로 잡을 수 있다.

## 결론
- **재현 로직(EBIT)은 2사례 연속 정상.** 괴리는 전부 **의도적 설계 차이**(세금 주입·터미널 정규화)에서 발생.
- 개선 A·B **구현 완료** → 엔진이 "비올 전용"에서 **"임의 실무 모델 수용"으로 확장**. 클래시스가 **3차 골든**(40,600원 정확 재현), 비올 8,413.38 무회귀.
- 모든 신규 필드는 옵셔널(None 기본) → 기존 경로 불변으로 회귀 0.
- checks.py가 공격적 가정을 실사례에서 포착 → 감사인 트랙 가치 입증.
