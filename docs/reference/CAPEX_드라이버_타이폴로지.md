# CAPEX 드라이버 타이폴로지

FCFF = `NOPAT + D&A − CAPEX − ΔNWC`. **CAPEX(재투자)**가 세 번째 다리 — 매출(NOPAT 견인)·
운전자본([[운전자본_드라이버_타이폴로지]])과 함께 현금흐름을 결정. 매출이 "P×Q, Q를 뭘로?",
WC가 "회전기일 고정 방법"이었다면, **CAPEX = 유지 + 신규, "유지를 상각비로·신규를 증설계획으로"**가
갈림길. 골든=[[DCF_교육_정본]]·[[모델러스_통합모델_5.4]]·[[리포트예시_클래시스]], 실전=SMIC.

## 핵심 공식 (실행 가능)
```
CAPEX = 유지(maintenance) + 신규(growth)
  유지CAPEX ≈ D&A(상각비 수준)                # steady-state: 자산 소모분 대체
  신규CAPEX = 증설 계획(announced Capa) 기반    # 성장 투자
% of Sales:   CAPEX = 매출 × capex_ratio        # 단순형
PPE 롤포워드: PPE_t = PPE_{t-1} + CAPEX − D&A    # 3표 연결 규율(모델러스)
```
→ [[가정원장_방법론]] 자기정합성 검산: `CAPEX_보고 ≟ % × 매출` 또는 `유지CAPEX ≟ D&A`.

## 드라이버 아키타입

| # | 방식 | 정의 | 출처 |
|---|---|---|---|
| X1 | **% of Sales** | CAPEX = 매출 × 일정 비율 | 모델러스 O121 |
| X2 | **유지 = 상각비 수준(D&A)** | 유지 CAPEX를 현 보유자산 상각비 수준으로 고정 | 클래시스·한화솔루션 |
| X3 | **유지 + 신규 분리** | 유지(상각비) + 증설/신규(계획) 별도 | 파마리서치·한화솔루션·케이씨(전방) |
| X4 | **증설계획 기반(announced)** | 발표된 캐파 증설 계획을 직접 반영 | Fluence·한화솔루션 |
| X5 | **PPE 롤포워드** | PPE_t = PPE_{t-1} + CAPEX − D&A (3표 연결) | 모델러스 R |

### X1. % of Sales
CAPEX를 매출의 일정 비율로. 모델러스 `O121 CAPEX = 매출 × %`. 빠르나 성장기·성숙기 자본집약도
변화를 못 담음. 자본집약 산업엔 부적합.

### X2. 유지 = 상각비 수준 (D&A)
성숙기 가정: **유지 CAPEX ≈ D&A**(자산 소모분만 대체). 클래시스 "현 보유자산 상각비 수준",
한화솔루션 "유지 CAPEX만 과거 상각비 토대로". CAPEX/D&A ≈ 1.

### X3. 유지 + 신규 분리 (정석)
`CAPEX = 유지(상각비 수준) + 신규(증설 계획)`. 파마리서치(유지 + 2공장 추가), 한화솔루션(유지
상각비 + 1만톤 증설), 케이씨(전방 삼성·SK의 유지 Capex + 신규 Capex를 증설 Capa 비례 분리).
가장 견고. **성장 국면일수록 신규 비중이 커져 CAPEX/D&A > 1**.

### X4. 증설계획 기반 (announced)
발표된 캐파 증설을 직접 반영. Fluence "2배 이상 증설 계획", 한화솔루션 "1만톤 증설 완료 반영".
가시성 높으나 계획 지연·취소 리스크 → 시점 가정 주의.

### X5. PPE 롤포워드
`PPE_t = PPE_{t-1} + CAPEX − D&A`. CAPEX를 대차대조표 유형자산과 **연결**하는 규율(모델러스 R).
CAPEX·D&A·PPE가 3표에서 일관돼야 함(스파인 대사).

## 교차 관찰 (매출·WC 타이폴로지와 대칭)
1. **CAPEX = 유지 + 신규로 분해**, 차이는 "유지를 뭘로(상각비 X2 / %매출 X1), 신규를 뭘로
   (증설계획 X4)". → 플랫폼 CAPEX 위저드 = 이 라우터.
2. **CAPEX/D&A 비율이 성장 국면의 신호**: >1 성장투자, ≈1 유지, <1 축소. 벤치마크 축.
3. **D&A도 별도 추정 필요** — 유지 CAPEX가 D&A에 연동되므로 순환. 보통 과거 유형자산 취득액
   평균이나 % of 유형자산으로(케이씨·파마리서치).
4. **PPE 롤포워드 정합성**(X5)이 감사 게이트 — CAPEX만 늘리고 PPE·D&A를 안 맞추면 3표 불일치.
5. **자기정합성 검산**: 리포트가 제시한 CAPEX/매출 또는 유지CAPEX=D&A가 자기 숫자와 맞는가?
   ([[가정원장_방법론]] claimed↔applied).

## 활용
- 플랫폼 CAPEX 라우터(X1~X5) + 유지/신규 분리 + PPE 롤포워드 게이트.
- CAPEX 벤치마크: 산업별 CAPEX/Sales·CAPEX/D&A 분포([[벤치마크_분포]] 확장 축).
- 가정 원장에 CAPEX 편입 → `CAPEX = %×매출` 또는 `유지CAPEX = D&A` 자기정합성 검산.
