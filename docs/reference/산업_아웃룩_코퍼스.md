# 산업 아웃룩 코퍼스 (産業 Outlook)

`D:\칼럼\` = PwC·삼일·삼정KPMG **산업 아웃룩 리포트 44편**(감사·M&A 방법론 제외). [[SMIC_기업
리포트_코퍼스]]가 *기업(企業)* 리포트라면 이건 *산업(産業)* 리포트 — **산업 구조·밸류체인·제품
taxonomy·TAM·CAGR·규제**를 준다. SMIC 리포트가 인용하는 "전방 시장 규모·산업 CAGR"의 원천.

> ⚠️ 기존 `docs/book/research/corpus`(ifrs 35 + val 27)는 **회계·공정가치 방법론** 목적
> (kifrs/methods 태깅). 산업 아웃룩은 그 코퍼스에 **미추출** → 밸류에이션 온톨로지 목적의
> **신규 추출**(이 코퍼스). 원본 비배포(전문은 `industry/_fulltext/`, 개인 RAG용).

## 원칙: 밸류체인 우선 (SMIC 종속 금지)
산업 문서는 **리포트 자체의 전체 밸류체인**(모든 단계·세그먼트·플레이어 — 비-SMIC 포함:
NVIDIA·OpenAI·ASML·Lockheed·롯데웰푸드·삼양식품 등)을 1차 지식으로 뽑는다. SMIC 33편은 각
밸류체인 단계에 걸리는 **사례**로만 매핑(`smic_companies`). 상단 플레이어(팹리스·모델·글로벌
방산사)는 우리 코퍼스에 기업 리포트가 없어도 **산업 노드로 존재**. → `key_players`(전체) ≠
`smic_companies`(사례).

## 통합 온톨로지 — 4계층
```
산업(産業)  ← 이 코퍼스 (TAM·CAGR·밸류체인·제품·규제)
  │ contains / value_chain
기업(企業)  ← [[SMIC_기업리포트_코퍼스]] (33편 큐레이션)
  │ has_segment
제품군(segment)  ← SMIC revenue_drivers[].segment
  │ driven_by
매출동인(A~K)  ← [[매출추정_논리_타이폴로지]]
```
→ "반도체 산업 TAM/CAGR → 케이씨 → 케이씨텍 세그먼트 → 전방Capex연동(A)"까지 한 그래프 탐색.

## 인제스트 (`scripts/industry_ingest.py`)
텍스트 우선 get_text() → `industry/_fulltext/`(전문) + `_extract/`(스텁). 구조화(value_chain·
products·tam·cagr)는 산문이라 사람/LLM 큐레이션(SMIC case doc과 동일).
