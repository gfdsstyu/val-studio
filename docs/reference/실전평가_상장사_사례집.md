# 실전평가 상장사 사례집 (2025~2026 시점 실측)

> **practice층 사료.** 프리미엄 칼럼의 상장사 실전평가 10선 증류 — 각 사례의 방법론·핵심 가정·
> 우리 게이트 관점 논평. ⚠️ **수치는 해당 기준일(2025~2026) 시점** — 사실이 아니라 "그 시점의
> 평가 판단" 기록으로 소비할 것. 공통 분석 순서: **(포괄)손익계산서 → 자본변동표 → 현금흐름표 →
> 재무상태표**(flow→stock 상호대사, [[모델링_워크플로우_기초]]와 정합).

## 공통 방법론 관찰
- **간이 DCF의 실무형**: FCF는 비현금손익·운전자본·CAPEX 변동성 때문에 간이 평가 요소로 부적합
  → **세후영업이익 × 배수(또는 성장 페이드 DCF)**가 반복 패턴(SK하이닉스·삼성·두산에너빌리티·APR).
  우리 스파인의 NOPLAT 계열과 동형.
- **DCF의 진짜 용도**: 목표주가 산출기가 아니라 **시장가격에 내재된 가정을 해부하는 프레임워크**
  (한화오션 결론) — 감사인 트랙 GapDiagnosis의 사상과 동일.
- **재무제표 두 줄 요약** 규율: "영업에서 X조 벌어 Y조 CAPEX, Z조 주주환원"(삼성 34/25/9조) —
  복잡한 대기업도 중요 거래만 솎아내면 단순화된다(한화에어로 원칙).

## 승격된 로직 (이 사례집 → 코드)
- **PSR 배수**(`multiples.py`): 지분 배수, stat(PSR) × 주당매출. 적자 성장기업 대안 — 흑자기업엔 보조.
- **`check_going_concern`**: 흑자도산 4신호(OCF 역설·유동비율·ICR·Debt/EBITDA) — 신호 다수면
  계속기업 DCF 자체가 무의미(청산가치 비교 국면).
- **`check_fcfe_usage`**([[DCF_교육_정본]] FCFE 절과 연결): FCFE는 핵심 변수를 재무구조로 이동 —
  Ke·levered β 강제(WACC 할인=FAIL), 차입 착시 판단, 목표 레버리지. **FCFF 음수라는 이유만으로
  FCFE 전환 금지**(성장기 음수는 '투자 중' — FCFF 유지+PSR 병행이 정석).

## E2E 재현 계획 (잔여)
1. **삼성전자**: 보유 XBRL 인제스트 → Brief → DCF 전 배관 독립 재현 → 칼럼 가정·결론 대조 리포트
   (감사인 GapDiagnosis 실전 데이터). 2. 알테오젠 PSR 워크플로우(RelativeSheet). 3. 한화오션
   수주잔고→매출 전환 모델(수주산업 프로파일 씨앗).
