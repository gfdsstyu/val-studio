# Peer/실무 DCF 템플릿 명세 — 클래시스·솔루엠

실제 애널리스트/실무 DCF 모델(암호화 pe양식)에서 추출한 **가정·로직**. 특히 **클래시스는 비올과 동일 업종(미용 의료기기)** 이라 마진·성장 구조의 직접 peer 벤치마크. 출처: `D:\Valuation\pe양식\` (복호화).

> 활용: (1) 비올류 평가 시 가정 sanity check, (2) WACC/마진 peer 비교, (3) 매출추정 방식(top-down 성장률) 레퍼런스.

---

## 1. 클래시스 (CLASSYS, 코스닥) — ⭐ 비올 동종업종

미용 의료기기(HIFU 등). 비올과 사업구조·마진 프로파일 유사 → **가장 가까운 peer**.

### 평가 결과
| 항목 | 값 |
|---|---|
| 현재주가 / 예측주가 | 48,850원 / 40,600원 → **Upside −16.9%** (고평가 판단) |
| 시가총액 | 31,264 억원 |
| Forward PER | 2024F **28.6x** / 2025F **24.6x** |
| 발행주식수 | 63,999,519 주 |

### 핵심 가정
| 가정 | 값·방법 |
|---|---|
| **WACC** | **6.24%** (유진투자증권 2024F 숫자 인용) |
| **Terminal Growth** | **5%** |
| **Revenue** | 2024 최신 컨센서스, **2025년부터 매년 +20% flat** |
| **COGS** | GP% **79.8%** 고정 (2024 수준 유지) |
| **SG&A** | EBIT% **51.6%** 고정 (영업이익률 유지) |
| 금융수익 | 25년 +20%, 26년 +10%, ~28년 +5%, 이후 +3% (보수적) |
| 금융비용·기타수익·기타비용 | 2024 수준 동일 유지 |
| EV 브리지 | (+)현금 (−)총부채 (−)소수지분, 2024F 숫자 |
| 할인 컨벤션 | **중간연도(mid-year)** Year Count 0.5,1.5,2.5,3.5,4.5 |

### 손익 투영 (백만원)
| | 2023A | 2024F | 2025F | 2026F | 2027F | 2028F |
|---|--:|--:|--:|--:|--:|--:|
| Revenue | 180,100 | 227,400 | 272,880 | 327,456 | 392,900 | 471,500 |
| yoy | 26.3% | — | 20% | 20% | 20% | 20% |
| GP% | 78.0% | 79.8% | 79.8% | 79.8% | 79.8% | 79.8% |
| EBIT% | 49.8% | 51.6% | 51.6% | 51.6% | 51.6% | 51.6% |

### DCF 결과 (백만원)
`ΣPV(FCF) 558,600 + PV(TV) 1,940,000 = EV 2,498,000` → (+)현금 199,400 (−)부채 99,400 = Equity 2,598,000 → ÷63.99백만주 = **40,600원/주**

### 비올 대비 시사점
- **마진 구조 거의 동일**: GP% ~79%, EBIT% ~51% (비올 EBIT% ~52%와 일치) → 동종업종 마진 벤치마크 신뢰.
- **WACC 격차 주목**: 클래시스 6.24% vs 비올 11.3%. 규모(시총 3조 vs 비올 소형)·베타·size premium 차이. 소형사 비올의 높은 WACC 합리성 방증.
- **성장 가정 단순화**: 20% flat top-down. 비올도 top-down 경로로 유사 적용 가능.
- **주의**: 성장주는 DCF 내재가치와 시장가 괴리 큼(모델 comment 명시) — 민감도·시나리오 필수.

## 2. 솔루엠 (SoluM, 코스피 248070)

전자부품(ESL 등). 미용기기 아님 — DCF 구조·CAPM 투명성 레퍼런스로 활용.

### 평가 결과
| 항목 | 값 |
|---|---|
| Implied / 현재 | 47,000원 / 25,350원 → **Upside +85.4%** |
| 발행주식수 | 48,837,144 주 |

### 핵심 가정
| 가정 | 값 |
|---|---|
| **WACC** | **4.25%** |
| **TGR(영구성장률)** | **2.5%** |
| Revenue growth | 12~14% |
| 할인 컨벤션 | Year Count 0.25 기준 (2023 3분기 기준일) |
| CAPEX 정의 | `sum(유형자산취득, 유형자산처분)`, % of sales |
| Change in NWC | `매출채권 + 재고자산 − 매입채무` |

### WACC 빌드업 (투명하게 노출됨)
```
WACC = We·Ke + Wd·Kd·(1−t)
Ke   = Rf + β·MRP
  Rf(무위험)          = 3.347%
  Beta               = 0.30       ← 낮은 베타
  Expected Mkt Return = 6.0%
  MRP                = 2.653%     ( = 6.0% − 3.347% )
  → Cost of Equity   = 4.143%
Kd(pre-tax)          = 5.612%
```
> β 0.3이 낮아 Ke가 4.14%로 매우 낮음 → WACC 4.25%. 우리 `wacc.build_wacc` 로 동일 재현 가능(검증 케이스 후보).

### 실무 인사이트 (모델 작성자 노트)
- 실제 모델은 매출·비용·D&A·ΔNWC·CAPEX 전부 추정 필요, **BS/CF/PL 상호 정합(OK 체크)** 이 나야 함.
- 상위 PE사일수록 **계정별 break-down이 세부적·논리적**. 예: 인건비를 "경제성장률 2%"로 두더라도 *왜* 그런지 시니어가 논리적으로 방어 가능해야 함 — 못 하면 다른 추정치 사용.
- → 우리 플랫폼의 **가정 provenance + LLM 근거 + 감사인 방어** 방향과 정확히 일치.

## 3. 두 모델 공통 로직 (우리 calc_core 와 정합)

| 요소 | 클래시스·솔루엠 | calc_core |
|---|---|---|
| FCF | `EBIT −Tax +D&A −CAPEX −ΔNWC` | 동일(`dcf.py`) |
| NWC | `매출채권+재고−매입채무` | `wc.py` 회전율 |
| 중간연도 할인 | Year Count 0.5,1.5… (클), 0.25 기준(솔) | `mid_year_periods` 파라미터화 |
| EV→Equity | EV +현금 −부채 −소수지분 | `non_operating_assets`, `net_debt` |
| Terminal | `FCF_last×(1+g)/(WACC−g)` | `dcf.py` (세금 재계산 포함) |

> 차이: 클래시스/솔루엄은 **NI/PBT 기반 약식**(금융손익 포함)인 반면 비올·calc_core는 **FCFF(EBIT 기반)** 정식. EV 브리지의 소수지분·현금 부호 컨벤션은 회사마다 상이 → `fs_mapper` NOA/IBD 분류로 흡수.
