# 채권수익률 기간구조·위험구조 — 할인율의 기초

> WACC의 Rf·kd, 복합금융상품(TF모형 신용스프레드·이자율모형)의 **기초 인프라**.
> [[deloitte_감사인검토_WACC방법론]]의 Rf·kd와 [[복합금융상품_평가]]의 이자율모형이 여기 뿌리를 둔다.

## 1. 기간구조 (Term Structure)
- **일반적으로 우상향**: 만기가 길수록 높은 수익률.
- **현물이자율(spot rate)**: 개별 현금흐름 할인용 순수할인율. **선도이자율(forward rate)**: 현물 커브에서
  도출한 미래 구간 이자율.
- **부트스트래핑(bootstrapping)**: 이표채 가격에서 이론 현물이자율 커브를 순차 추출.

### 기간구조 4이론
| 이론 | 설명 |
|---|---|
| **기대이론** | 수익률곡선 = 미래 이자율에 대한 투자자 예상 |
| **유동성프리미엄이론** | 장기 보유 위험에 추가 보상 요구(우상향 설명) |
| **시장분할이론** | 만기별로 투자자군이 분리 |
| **선호영역이론** | 충분한 프리미엄이면 선호 만기 이탈 |

## 2. 위험구조 (Risk Structure) — 신용스프레드
```
수익률스프레드 = 채무불이행위험프리미엄 + 위험프리미엄
```
- 동일 만기 채권 간: 약속수익률 ↔ 기대수익률 ↔ 무위험이자율 관계로 발행자 신용위험 정량화.
- → **kd 산정**([[deloitte_감사인검토_WACC방법론]] 신용등급×만기 매트릭스)과
  **TF모형의 채권성분 할인율**([[복합금융상품_평가]])의 이론 기반.

## 3. 평가 실무 연결
| 용도 | 사용 |
|---|---|
| **WACC Rf** | 국고채 커브(평가기준일, 장기물) |
| **kd** | Rf + 신용스프레드(등급·만기) |
| **복합금융상품** | 이자율모형(BDT·Vasicek·HW)은 커브 전체가 입력. 혼합할인율(TF)은 신용스프레드로 채권성분 할인 |
| **다통화 SOTP** | 통화별 커브([[외부평가의견서_고정양식_구조]] JPY·VND 사례) |
