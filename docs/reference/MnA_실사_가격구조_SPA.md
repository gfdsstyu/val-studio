# M&A 실사·인수가격 구조·SPA — 딜 관점의 정본

> 출처: 중소벤처기업부·S사회계법인 「M&A ESSENCE」(2020, 358p) 제3~4장.
> [[FDD_재무실사_정상화]](QOE·NWC peg 개념)의 **딜 프로세스 확장판** — 실사가
> 가격·계약과 어떻게 맞물리는지가 골자. 감사인 트랙·상대가치 정상화의 근거 사전.

## 1. 인수가격 결정 구조 ⭐ (전체 지도)

```
[Valuation]  EV = EBITDA×Multiple 또는 DCF   ← QoE(이익의 질)가 좌우
[DD]         (−) 순차입금·부채성 항목(Net Debt & Debt-like) → 지분가치
             = SPA 의 기준가격(Base Price) — Cash-free/Debt-free
[SPA]        (±) 가격조정(Purchase Price Adjustment): 순부채 조정 + 운전자본
             조정(확정 vs 목표운전자본 차이) − 이연대가(Earn-out) ± 기타
             = 최종 거래가격
```
- **Cash-free/Debt-free**: 현금은 "파운드 당 파운드"로 정산, 부채는 거래가에서 차감.
- 실사(평가)기준일↔거래종결일 사이 재무 변동이 가격조정의 존재 이유.

## 2. 실사의 단계·주체·범위

| 단계 | 시점 | 목적 |
|---|---|---|
| 예비실사 | 잠재 인수후보 선정 후 | 제한된 정보로 인수가능성·Indicative Offer 가이드 |
| 정밀실사(본실사) | Short-list/우협 선정·MOU 후 | 전 부문 정밀 — Binding Offer 가격 가이드·진술보장 반영사항 |
| 확인실사 | 우협 선정~SPA 서명 | 본실사 쟁점·**가격조정에 초점** → 기준가격 협의 |
| 정산실사 | SPA 체결·종결 후 | 기준일~종결일 가격변동 확인·정산 |

- 중소벤처 딜은 예비+본실사 동시, 정산실사 생략도 흔함.
- **VDD(매도자실사)**: 매도자가 외부 전문가로 수행 — Deal Breaker 조기 발견·기간 단축.
- 실사 범위 축: Business(산업·고객·R&D·HR)·Financial·Legal — FDD 는 **QoE·
  운전자본·Net Debt/부채성 항목·비영업 자산부채** 중심. 손익 과거 3~5개년.
- 실사 절차 10단계: 계약(이해상충 확인)→예비분석(IM·공시)→협상이슈→일정→**평가팀과
  사전 소통(Valuation Issue 가 실사 범위를 정함)**→자료요청(Dataroom)→분장→사실확인
  문서화→경영진 인터뷰→수행.
- 실사 산출물 4분류: 거래중단 요소(Deal Breaker)·가치평가 요소·사후통합 요소·계약 요소.

## 3. QoE — 이익의 질 조정 사다리 ⭐

```
Reported EBITDA (공시 재무제표)
 ± Management Adjustments (회사 제시 조정)
 = 회사제시 수정 EBITDA
 ± QoE Adjustments (실사 조정: Normalization·Pro-forma)
 = Adjusted EBITDA (분석 기준 — 멀티플·DCF 의 분모/출발점)
```
QoE 조정 항목: 비경상·일회성 거래(일회성 매출처·구조조정비) / 영업 무관(고정자산
매각·오너 개인비용) / 비현금(주식보상·충당부채) / 회계 오류·정책 변경 / 특수관계자
거래의 M&A 후 유지·변동 효과 / **Stand-alone Cost**(사업부 양수도 시 독립법인 비용).
가치·위험 분석: 매출(제품·고객 유지율·채널·시장·**계절성** — [[상대가치_계절성_LTM]])
× 원가(원재료·인력·고정/변동·CAPEX) × Margin 추이 × 비재무(규제·노무).

## 4. Net Debt & Debt-like Items — 숨겨진 부채

- 식별 체크: SPA 의 "부채"·"현금" 정의가 올바른가 / 누락 없는 분류 / 당사자 합의 /
  **부외부채·우발부채·현금유출 약정** 존재 여부.
- 구성: 현금성(만기 3개월 내) / 이자부부채(차입·금융리스) / **부채성 항목**(미지급이자·
  퇴직급여충당부채·미지급배당·소송 지급의무 — 자산성 항목은 반대 가산) /
  가치조정(사용제한현금·사외적립 미납) / 부외·우발(소송·스톡옵션 현금유출·운용리스).
- → 우리 엔진의 EV→Equity 브리지(net_debt·non_operating_assets)가 실무에서
  이만큼 두꺼운 계층이라는 뜻 — NOA/IBD 분류(fs_mapper)의 정본 근거.

## 5. 운전자본 — 적정 vs 목표, 그리고 두 함정 ⭐

- **적정운전자본**: 장부 운전자본에 비경상 사건(팩토링·대금지급 연기·셧다운) 조정 →
  조정운전자본으로 실질 추세 분석. DIO·DSO·DPO·CCC 추이 병행. 손익 추세와
  자산 추세의 불일치(밀어내기 매출→채권 급증, 팩토링→채권 급감)가 적신호.
- **목표운전자본**(Completion Accounts 정산 기준점): 매도자는 낮게, 인수자는 높게
  잡을 유인 — 경영진 제시 가정의 면밀 검토 필수.
- **함정 ① 계절성 사업**: 월별 100→1,200 사이클에서 연평균(650)을 목표로 잡으면
  8월 종결 시 실제 1,200 → 인수자가 550 만큼 가격 상향 정산 손해.
- **함정 ② 성장 사업**: 성장 추세 무시하고 전년 평균(1,850)으로 잡으면 종결 시점
  실제 3,200 → 1,350 상향 정산 손해. **평균이 아니라 종결 시점 추정이 기준**.

## 6. SPA(주식매매계약서) 7 조항

정의(회계기준·목표운전자본·**MAE**: 통상 거래가/순자산의 10~20% 부정적 영향 =
해제 사유) / 매매 대상·기준가격·가격조정 / **진술과 보장** / 확약 / 선결조건 / 해제 /
손해배상. 초안은 Short-list 배포 후 마크업 협상. 실사 결과와 정의 조항의 일관성
검증이 실사의 마지막 임무.

## 7. 가격조정 3방식 비교 ⭐

| | Completion Accounts | Locked Box | Earn-out |
|---|---|---|---|
| 기준 | **거래종결일** 재무제표로 순부채·운전자본 정산 | Locked Box Date(기준일) 금액 고정, 추가 정산 없음 | 종결 후 성과(EBITDA·매출 등) 충족 시 추가 지급 |
| 장점 | 종결시점 실제치 반영(정산 기회) | 가격 확실성·단순(매도자 경쟁입찰 선호) | 가격 이견 클 때 합의 가능(성장·기술 기업) |
| 단점 | 종결일 재무제표 준비 비용·시간 | 유출(Leakage) 방지 확약 필요·악화 대비 미흡·Carve-out 부적합 | 2~3년 성과 감시·조작/공정성 분쟁 |
| 핵심 정의 | 종결일 F/S 작성주체·회계정책(합의>법정>GAAP 계층)·검토 절차 | Permitted/Unpermitted **Leakage** 목록 | 성과 지표·측정 방식 |

정산 산식: 기준가격 + 현금 − 순차입·부채성(순부채 조정) ± (확정운전자본 − 목표운전자본)
− 이연대가 ± 기타 = **최종 거래가격**. 순부채·운전자본 조정은 매도자의 종결 전
채권 회수/채무 미상환 꼼수를 막기 위해 **함께** 쓰인다.

**가격조정 3중 장치**(사례집 실측 — 빙그레·해태아이스크림 75억 조정 해설):
- **De Minimis**: 개별 조정사항의 최소 청구 단위 — 미만 항목은 청구·Basket 산입 불가.
- **Basket/Threshold**: 조정사항 총합이 임계 초과 시에만 조정 발동.
- **Cap**: 조정 총액 상한.
- 수치예: De Minimis 1억·Basket 100억·Cap 150억, 조정사항 {5천만, 20억, 200억}
  → 5천만 차단, 나머지 합 220억 청구 가능하나 **150억까지만** 조정.

## 8. 평가 활용목적 3분류 (우리 스코프 로드맵과 정합)
거래 목적(양수도·투자) / 재무보고 목적(**PPA·손상·공정가치** — [[PPA_무형자산평가]]
[[손상검사_impairment]]) / 법규·세무(합병비율·양수도 **외부평가의견서**·상증세 평가 —
[[외부평가의견서_고정양식_구조]] [[합병_주식교환_방법론]]). 가이드 자체가 우리
트랙 지도를 확인해준다.

## 우리 플랫폼 매핑
- QoE 사다리 = 상대가치·DCF 투입 전 **정상화 파이프라인**(Reported→Adjusted) —
  normalization 은 [[상대가치_계절성_LTM]] LTM 과 별개 축(일회성 제거 vs 기간 보정).
- 목표운전자본 함정 2종 → 검증규칙 후보: 계절성·성장 사업에서 "평균 기반 목표
  운전자본" 감지 WARN(월별/분기 시계열 필요).
- SPA 가격조정 산식 = merger/브리지 리포트의 정산 슬롯 템플릿.
- Deal Breaker·가치평가·사후통합·계약 4분류 = 실사 리포트 산출 구조.
