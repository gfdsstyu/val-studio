# 손상검사 (Impairment Test)

> **밸류에이션의 다른 목적축.** 우리 북 대부분은 "합병·양수도 평가"(계속기업 DCF, 거래가치)지만,
> 손상검사는 **자산 장부금액이 회수가능한가**를 보는 회계목적 평가다. DCF를 쓰되 **규칙이 다르다**.
> 출처: joy-accounting.netlify.app(회계 실무 블로그). 회계법인 자료 CGU 조각([[감사인검토_WACC방법론]])과 연결.

---

## 1. 기본 원리
```
손상 = 장부금액 > 회수가능액  →  차액을 손상차손(비용) 인식
회수가능액 = max(FVLCD 순공정가치, VIU 사용가치)
```
- 둘 중 **하나만 장부금액 초과해도** 손상 아님 → 다른 방법 계산 불요(실무 절약).
- **손상의 중심축은 VIU(사용가치)** — 회사가 자산을 현 상태로 계속 사용할 때의 가치. DCF로 산정.

### ⭐ VIU vs FVLCD — 관점이 정반대 (핵심 구분)
| | **VIU (사용가치)** | **FVLCD (순공정가치)** |
|---|---|---|
| 관점 | **entity-specific**(회사 고유) | **market-participant**(시장참여자) |
| 현금흐름 | 회사 현 상태 계속 사용 | 시장참여자가 볼 현금흐름 |
| 성능향상 CAPEX | **제외**(현상유지만) | 시장참여자 관점 반영 가능 |
| 시너지 | **owner synergy 제외** | **시장참여자 시너지 포함 가능** |
| 할인율 | **세전**(기준서) | 시장 기준 |
| 처분비용 | 미차감 | **차감** |
> **손상 = VIU 중심**이지만 FVLCD가 더 크면 그걸로. FV 평가(합병·양수도·PPA)는 market-participant
> 기준이라 VIU와 규칙이 다르다 — 회계법인 자료도 이 경계·CGU를 다룸([[감사인검토_WACC방법론]]).

## 2. CGU (현금창출단위, Cash-Generating Unit)
- 개별 자산이 **독립적 현금흐름을 못 내면**, 현금흐름을 공유하는 최소 자산군(CGU)으로 묶어 평가.
- **영업권(goodwill)은 반드시 CGU 수준에서만** 손상검사. 개별로 못 함.

## 3. 매년 필수 손상검사 대상 (손상징후 무관)
- 내용연수 **비한정** 무형자산
- 아직 사용하지 않는 무형자산
- 사업결합으로 취득한 **영업권**

## 4. 손상징후 (Triggering Events) — 나머지 자산
| 외부 | 내부 |
|---|---|
| 시장가치 급락, 경제·기술환경 악화 | 물리적 손상, 유휴화 |
| 금리 상승(→할인율↑) | 경제적 성과 부진 |
| **시가총액 < 순자산 장부금액** | 구조조정·처분 계획 |

## 5. ⭐ 손상검사 DCF ≠ 일반 밸류에이션 DCF
| 항목 | 일반 평가(거래) | 손상검사 |
|---|---|---|
| 기간 | 계속기업(영구, TV 포함) | **자산 내용연수 기간** (영구 아님) |
| CAPEX | 성장 반영 | **성능 향상 CAPEX 제외**(현상유지만) |
| 시너지 | 매수자 시너지 반영 가능 | **owner-specific synergy 제거**(회사 고유 기대 배제) |
| 관점 | 거래 당사자 | 시장참여자(entity-specific 아님) |

→ 우리 엔진으로 손상검사 시: `terminal_fcff_override=0`(TV 없음/내용연수 종료) + 성능향상 CAPEX 배제한
현금흐름 + 내용연수 길이의 명시기간. 별도 프로파일(향후 `impairment` 모드).

## 6. 할인율 — 시장관점 우선 + 유효세전율 (Issue Paper 234 정본)
- **① 시장관점 우선**: 동일/유사 거래가 관측되면 **그 거래에 내재된 할인율** 사용 — CAPM WACC는
  관측정보 없을 때의 **대용치(surrogate)**(β조차 동종 상장 평균의 간접추정). 대용치 사용 시
  size/country/liquidity premium 가산으로 완성.
- **② 유효세전율**: IAS 36은 세전 현금흐름·세전 할인율 요구. 실무 정석 = **세후 기준으로 계산한 뒤
  세전 VIU == 세후 VIU가 되는 유효세전율을 시행착오 역산**. **세전율 ≠ 세후율의 단순 Gross-Up**
  (gross-up은 우연히만 일치 — 현금흐름 시점 분포에 의존).
- 게이트: `check_viu_discount_rate`(관측 할인율 우선·gross-up 감지·세전/세후 VIU 일치).

## 6b. 금지 현금흐름 목록 (Issue Paper 745 — '현금흐름 순수성')
| 배제 대상 | 이유 |
|---|---|
| **금융활동**(이자·차입 원리금) | 차입원가는 **할인율(WACC)에 기반영** — 포함 시 이중계산. 이자 차감 현금흐름이면 WACC 아닌 Ke로 할인해야(분자·분모 대응 — Case 2 오류) |
| **법인세** | 세전 기준(§6 유효세전율 경로로 정합) |
| **미확정 구조조정** 절감 | IAS 37 요건(구체적·공표·임박) 충족 전 배제. 효율성 개선은 구체 실행계획+현상유지 전제 시 조건부 포함 |
| **성능 개선/향상 CAPEX·효과** | VIU는 자산의 **현재 상태** 기준(현상유지만) |
| **이미 인식된 부채 관련 유출**(복구충당 등) | 장부금액에 기반영 — 중복차감 방지(§7b) |
| 비현금항목(감가상각 등) | 현금유출 아님 |
- 기타: Base=경영진 승인 예산(달성이력 검토), g\* ≤ 산업·국가 장기평균(0·음수 허용), 예측기간
  정당화 없으면 **5년 이하**, 기업자산 배분 시 유지·감가 유출도 함께 배분.
- 게이트: `check_viu_cashflow_scope`(위반 플래그별 WARN + 예측기간 5년).

## 7. 장부금액 정합 — like-for-like (Issue Paper 235)
- **DCF가 산출하는 것은 영업가치** → 비영업자산(투자주식)·비영업부채(차입금)는 비교 장부금액에서
  제외. **DCF 현금흐름이 운전자본 변동을 포함하면 장부금액에도 운전자본 포함**(대칭).
- **터미널 WC 함정**: DCF는 통상 추정기간:영구 = **3:7**로 터미널 비중이 높음 — 부(−)의 운전자본이
  지속되는 회사는 5년차 ΔWC를 영구에 그대로 투영하지 않는지 검토. 터미널 WC는 g와 일관
  (우리 `terminal_wc_ratio` = 이 원칙의 엔진 구현, [[DCF_교육_정본]] 정규화 공식).

## 7b. 복구충당부채 CGU (Issue Paper 746 — 일관성 조정 수치예제)
광산 장부 1,000 − 복구충당부채 500 = **순 장부금액 500**과 비교. VIU는 복구 유출 **제외**하고
계산(700 산출 과정에서 충당부채 500 차감) — FVLCD(800, 의무 이전 반영)와 **동일 척도**.
회수가능액 = max(800, 700) = 800 > 500 → 손상 없음.
**규칙: 복구 유출을 현금흐름과 장부금액(충당부채) 중 하나로만 반영**(중복차감 금지).

## 7c. 사업결합 DTL → 즉시손상 역설 (Issue Paper 413)
무형자산 DTL 인식(IAS 12.66) → 상대계정 영업권 증가. VIU는 세전이라 산정기준이 어긋나
**인수 직후 영업권이 손상된 것처럼 보이는 구조적 상충**. 정상 사업결합(공정 가격·headroom)이면
즉시손상 인식 안 함이 관행 — 근거: FVLCD는 세후 기준 / VIU headroom / 해당 DTL을 CGU 순자산에
포함하는 해석(IAS 36.78). 예외: overpaid·인수 직후 실적 급락.

## 8. 손상차손 인식 순서
```
1순위: 영업권 전액
2순위: CGU 내 다른 자산에 장부금액 비례배분
3순위: 특정 자산이 하한(개별 회수가능액) 도달 시, 나머지에 재비례배분
```

## 9. 비지배지분 (NCI) Gross-up
- 지배지분만 영업권 인식(부분영업권법)했는데 손상검사는 CGU 전체 → **비지배지분 몫 영업권을 gross-up**해
  손상검사, 인식된 손상차손 중 NCI 귀속분은 배분.

## 9b. 실무 뉘앙스 (polaris 블로그)
- **⭐ 시가총액 = 자사주 제외(유통주식수)**: 기업가치평가·K-IFRS 1036 손상징후(문단12(4)) 시총 비교는
  **유통주식수(총발행 − 자사주)** 사용. KRX 기본 시총은 자사주 포함이라 과대 → 자사주만큼 제외해야
  정확. 순자산(BV)에 이미 자사주 반영되어 있으니 시총도 동일 기준. **우리 DCF 지분가치·주당가치도
  유통주식수 기준**(자사주 있는 회사 주의).
- **추정기간 5년(K-IFRS 1036)**: 더 긴 기간 정당화 사유 없으면 5년. 후속연도 성장률은 **일정·하락·0·
  음수** 가능(제품/산업 수명주기 부합해야 상승). ※ 손상 목적 아니면 5년 절대규칙 아님.
- **감리 지적사례**: 종속기업투자주식 손상징후(지속영업손실·순자산 하락) 있는데 미수행 → 과대계상.
  매출 과대추정으로 취득가 과대 후 손상 회피. → 감사인은 손상징후 시 **독립 외부평가기관** 손상검사 권고.

## 9c. 외부 손상징후의 구조적 처리 (Issue Paper 747) + 관리종목 PxQ (FSS 2020-33)
- **시총 < 순자산 = 명백한 외부 trigger**(IAS 36.12(d))이나 특정 자산에 직결되지 않는 광범위 신호 —
  **전사 일괄감액 금지**, 실질 영향 자산·CGU를 판단으로 식별해 각각 회수가능액 추정.
  절차: 영업권 배분 CGU 우선(36.90~96, 연 1회 필수) → CGU별 max(FVLCD, VIU) vs 장부 →
  손상 시 영업권 먼저 차감(36.104). headroom 있으면 분개 없음.
- **관리종목 관계기업주식**(FSS 질의회신 2020-33): 30분 단위 거래 등 제한이 있어도 소액주주 지분이
  지속 거래·공시되면 **활성시장 공시가격** → 순공정가치 = **PxQ − 처분부대원가**(K-IFRS 1113.80,
  [[공정가치_측정_FV]] §2 PxQ와 연결). 회수가능액 증가 시 손상 환입(단일자산).

## 10. 우리 플랫폼 반영 (🔨 게이트 3종 승격, 엔진 모드는 후속)
- **게이트(구현됨)**: `check_viu_discount_rate`(시장관점 우선·gross-up 감지·세전/세후 VIU 일치) ·
  `check_viu_cashflow_scope`(금융활동/법인세/미확정 구조조정/성능향상 CAPEX/복구충당 중복차감 +
  예측기간 5년) · `check_impairment_trigger`(시총<순자산 — **자사주 제외 유통주식수** 기준, §9b).
- **impairment/VIU 엔진 모드(⏳ 후속)**: 새 엔진이 아니라 기존 `dcf.py` 스파인의 **제약 모드** —
  TV 미포함(내용연수)·성능향상 CAPEX 필터·세전 관점(유효세전율 역산기)·회수가능액=max(FVLCD, VIU).
- FV 평가(market-participant)와 VIU(entity-specific)의 경계 규칙(§1 표)을 프로파일로 강제 예정.
