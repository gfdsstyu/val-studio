# 참고보고서(증권사·산업 IR 리포트) 활용 설계

`D:\Valuation\DCF_비올\참고보고서\` = **메인 벤치마크 비올을 평가할 때 참고한 IR·증권사·산업 리포트**.
이들은 플랫폼의 **RAG 지식원천 코퍼스 + 가정 provenance의 원천**이다.

> 3rd-party 저작물 → 로컬 분석용으로만 처리(청킹·임베딩), 재배포·레포 포함 안 함.

---

## 1. 리포트 인벤토리 (분류)

| 분류 | 파일 | 용도 |
|---|---|---|
| **비올 증권사** | 23_01·24_03 비올_유안타, 240325_하나, 24_01_신한, 24_04_ebest, 24_04_viol_sk, 비올_리튼 | 매출·EBIT 추정, 목표주가, RF 장비/소모품 구분, 컨센서스 |
| **산업** | 23_01_중소형미용기기산업분석, 산업리서치-anti-aging_20240510 | 시장규모·**CAGR**(top-down 입력) |
| **Peer** | 제이시스메디칼, 에이피알(수정보고서) | peer 마진·성장 벤치마크 |

### 추출된 핵심 수치(예시)
- 산업분석: 미용 의료기기 시장 **2030 CAGR +14%**, 뷰티 **+16%**, 소모품 고성장(RF 등). → `revenue.top_down(cagr=0.14)`.
- 유안타: RF 장비/소모품 매출구조, 목표주가 등급(Outperform/Marketperform/Underperform), 경쟁사(InMode·Serendia·Cartessa) 동향.

---

## 2. 활용 패턴 (플랫폼 컴포넌트 매핑)

### ① RAG 지식원천 코퍼스 (`rag/corpora.py`)
- 3-코퍼스 중 **지식원천**에 적재(기초 컨텍스트=사업보고서/IR 과 분리, 신뢰수준 태깅).
- 청킹: `rag/chunker.py`(표 atomic, 섹션 heading provenance). 각 청크에 `{source: '유안타 24.03', section: 'RF소모품 전망', page}`.

### ② 산업 CAGR → top-down 매출추정 (`revenue.top_down`)
- 산업 리포트의 시장규모·CAGR·점유율을 `market_size / cagr / share` 입력으로.
- 리포트 예시(클래시스)가 "글로벌·국내 미용기기 시장 전망치 준용"한 것과 동일 경로.

### ③ 증권사 컨센서스 종합 (assist / consensus)
- 여러 증권사 목표주가·매출·EBIT 추정치 → **컨센서스 밴드**(min/median/max) → 시나리오(base/upside/downside) 시드.
- 클래시스가 "2024 최신 컨센서스" 인용한 방식. 우리 `6.시나리오` 3-case 시드.

### ④ 가정 provenance (`assist/provenance.py`)
- 챗이 도출한 각 가정(매출성장률·마진·시장 CAGR)에 **근거 인용** 태깅: "이 가정은 [유안타 24.03 §RF소모품 전망]에 근거".
- Self-RAG citation 검증(감린이 chatHandler 포팅) → 미지원 인용 제거.
- → 감사인이 "왜 이 성장률?" 물으면 원문 청크로 즉시 방어.

### ⑤ 감사인 트랙 대조 (`auditor/tests.py`)
- 평가자가 쓴 가정 vs 증권사 컨센서스/산업 CAGR **대조 테스트** → 유의적 차이 플래그.
- 예: 평가 매출성장 20% vs 컨센서스 중앙값 15% → "낙관 편의" 지적.

## 3. 파이프라인 (참고보고서 → 가정)

```
참고보고서 PDF
  → parsers/pdf.py (pdftotext/PyMuPDF, 표 파싱)
  → rag/chunker.py (섹션·표 provenance)
  → rag/ingest.py (지식원천 코퍼스, 임베딩)
  → assist/chat.py: "비올 소모품 성장률 근거?" 검색
     → 유안타/산업분석 청크 인용 + LLM 가정 제안
  → 유저 승인 → 가정 확정(provenance 부착) → calc_core
  → 감사인 트랙: 가정 ↔ 컨센서스 대조
```

## 4. 우선순위
- **P1**: 산업 리포트 CAGR → top-down 매출추정(가장 직접적, 즉시 가치).
- **P2**: 증권사 컨센서스 종합 → 시나리오 시드.
- **P3**: 전체 RAG 지식원천 + provenance 인용(감사 방어).

> 기초 컨텍스트(사업보고서·경영진 자료)와 **분리 관리**: 참고보고서는 외부 3rd-party 애널리스트 관점 → 신뢰수준·편의(증권사 매수편향) 태깅해서 별도 가중.
