# 영구성장률(Perpetual/Terminal Growth Rate) 적합성

출처: 실무 이슈 노트(DCF 영구성장율 0~1% 적합성). `모델링_실무_2강4강.md` TV 절 심화.
**TV가 전체가치의 ~75%** → PGR은 결과값 최고 민감 파라미터. 우리 `dcf` 엔진의 필수 경고·민감도 대상.

---

## 0. 왜 중요한가 — TV 비중
- **영구현금흐름(6년~) 가치 : 추정기간(~5년) 가치 ≈ 75 : 25** (필자 경험 최빈).
- 최종값 3/4가 **PGR·WACC 두 파라미터**에 좌우 → 작은 PGR 변화가 큰 가치 변동.
```
TV = 추정기간말 FCFF × (1 + PGR) / (WACC − PGR)     (Gordon Growth)
PV(TV) = TV / (1 + WACC)^n
```

## 1. 한국 실무 관행: 0% 또는 1%
### 0% — 보수주의
- 현금흐름이 영구히 일정 유지 가정. **과대평가 방지**(가장 보수적).
- 근거: 미래 성장 추정 불확실성 + 성숙단계 도달 시 성장 미미.

### 1% — 완만한 안정 성장
- 물가상승률보다 약간 높고 **GDP 성장률보다 낮은** 매우 완만한 성장.
- 제한적·완만 성장의 **안정 산업군**에 적합.

### 공통 근거
1. **보수·현실주의**: 추정 불확실성 + 성숙 성장곡선.
2. **경제/산업 정합**: PGR이 **장기 GDP 성장률 초과 = 비현실적**(영구히 경제 추월 불가). 안정기·후퇴기 산업에 0~1% 적합.
3. **과대추정 위험 경감**: TV 비중이 클수록 낙관 추정 완화 효과 큼.

## 2. 글로벌 Practice: 2~4% (평균 3%)
- global practice는 0·1% 외 **역사적 물가상승률 + GDP 성장률 고려 2~4%**가 더 다수로 보고.
- **"무조건 0~1%" 아님** — 아래로 적정 선택:

| 고려요소 | 낮은 PGR (0~1%) | 높은 PGR (2~4%) |
|---|---|---|
| **성장단계** | 성숙·안정 현금흐름 | 급성장(합리적 범위 내) |
| **산업 변동성** | 제한적 성장·치열한 경쟁 | 성장 여력 산업 |
| **경제조건** | 후퇴·불확실성 큼 | 정상 성장 전망 |
| **불확실성** | 추정 불확실성 커 보수 필요 | 예측 안정적 |

## 3. 종합 원칙
- **관행 기본값 = 2~4%(평균 3%)**. 물가+GDP 근거.
- **0~1%는 정당화 조건부**: 제한적 성장 전망 / 성숙단계 / 불확실성 커 보수적 접근 필요 시 (과대평가 방지).
- **철칙: PGR ≤ 장기 GDP 성장률** (반드시). PGR < WACC (Gordon 수렴 조건).

## 4. `dcf` 엔진 반영
| 개념 | 구현 |
|---|---|
| PGR 입력 | `DcfInputs.perpetual_growth_rate` (자유입력, 기본 관행값 힌트) |
| **TV 비중 자동표기** | `dcf.run` 결과에 `tv_weight_pct` (PV(TV)/EV) — 75% 근처면 강조 |
| **PGR > GDP 경고** | validator: PGR > 장기 GDP(한국 ~2%, 글로벌 GDP) → WARN |
| **PGR ≥ WACC 오류** | validator: Gordon 발산 → ERROR |
| **PGR 민감도** | 0%/1%/2%/3%/4% 그리드 자동 산출(WACC와 2D) |
| 근거 메타 | `pgr_rationale`(성장단계·산업·경제조건) provenance |

> 감사인 트랙: "PGR 3%" 단독이 아니라 **"PGR 3% (물가2%+실질성장, GDP 2.x% 이내, 성숙단계, TV 비중 74%)"** — 근거·임계값·비중까지 추적. 0~1% 채택 시 "보수적 접근 사유" 명시 요구.
