# 주식기준보상·희석 주당가치 (SBC) — 🔨 희석 브리지 구현

> 원천: IFRS Issue Paper 222/225/227/228/731(옵션평가) + 524(희석EPS) + 526(다모다란
> 주당가치) + 742/743(VIU의 SBC). 엔진: `dcf.py` 희석 브리지(`dilutive_claims_value`) +
> 게이트 2종. 옵션평가 수학은 [[복합금융상품_평가]]의 CRR/BSM과 공유.

## 1. 옵션평가 모형 선택 (IFRS 2)
| 모형 | 적합 | 한계 |
|---|---|---|
| **BSM(폐형)** | Plain-vanilla European | 시장조건·조기행사 미반영 |
| **Lattice(이항)** | American ESO·조기행사 지표(주가=행사가 2배 등) 노드별 반영 | 시장조건이 행사시점과 다르면 부적합 |
| **Monte-Carlo** | 시장조건(목표주가 path)·복잡 조건 | 비용·구현 부담 |

- 동일 가정이면 결과 대체로 유사, **노드 수 증가 시 Lattice → BSM 수렴**(227).
- **조기행사**: 지표가 신뢰성 있으면 Lattice/MC로, 없으면 기대기간 근사. 기대기간은
  단순평균 대신 **행사기간별 층화(stratify)** — 기간 2배 ≠ 가치 2배(비선형)(222).
- ESO 특성(228): 양도불가·blackout·10년 만기·조기행사 경향 → European 가정 부적절.

### 시장조건 vs 가득조건 (225 — grant date approach)
- **시장조건**(목표주가): **부여시점 공정가치에만 반영**, 후속 미충족이어도 재측정 없이 비용 안분.
- **가득조건**(근무·수량): 공정가치에 미반영, 후속기간 **수량 조정**으로 반영.
- 이 grant-date 고정이 IFRS 2가 IFRS 9/13 밖(out-scope)인 이유([[공정가치_측정_FV]] §1).

### 변동성 (731)
- **Vega > 0**: 변동성은 옵션가치에 항상 정(+) — 비대칭 수익구조 + 로그정규 우측꼬리.
  σ=0이면 옵션의 초과가치 없음(무위험 등가). **OTM도 시간가치가 있어 0 처리 금지**(TSM 비판과 연결).
- **비상장 σ 추정 절차**: 유사 상장 peer(사업모델·규모·상장연한)의 **3년 월별 종가 연율화
  변동성(×√12)의 (가중)평균** + 이례기간(팬데믹 등) 제외/보정·평균회귀 고려 5~10% 하향 가능.
  β 산출과 동일 원리(peer 기반 — [[베타_Bloomberg_vs_KICPA]]).
- 이상치 정제(IQR·MAD)는 [[복합금융상품_평가]] §6.

## 2. 희석 주당가치 — TSM vs 다모다란 가치차감법 (526)
| | TSM(자기주식법) | **다모다란 가치차감법(권장)** |
|---|---|---|
| 조정 위치 | **분모**(행사대금으로 자사주 매입 가정, 순증 주식수) | **분자**(모든 옵션 FV를 지분가치에서 차감) |
| 분모 | 희석 주식수 | **기본 주식수** |
| OTM 옵션 | **완전 무시**(행사 안 함 가정) | BSM 등으로 **시간가치 포함** 반영 |
| 예시(기본 1억주·옵션 1천만개·X=$10·E=$10억) | ITM($15): $9.68 / OTM($8): $10.00 | OTM이어도 옵션 FV만큼 차감 → $10.00 미만 |

- **TSM의 결함**: 시간가치 미반영·OTM 절벽(ATM 옵션 영향 무시) — 옵션은 OTM이어도 미래
  잠재 청구권으로서 가치를 가진다.
- **엔진 구현**: `DcfSpineInput.dilutive_claims_value`(옵션·워런트·전환권 FV 합, 백만원) →
  주당가치 = (지분가치 − 희석청구권 FV) ÷ **기본 주식수**. `equity_value`는 총 지분으로
  유지(감사추적 분리). RCPS/CB의 FV는 [[복합금융상품_평가]] 엔진(`convertible.py`·TF)으로
  산출해 여기 주입 — 두 트랙의 연결점.
- 게이트 `check_dilution_bridge`: 전환증권 존재+미반영 → WARN / TSM 사용 → 한계 WARN.

### 희석 EPS와의 구분 (524 — IAS 33 규약)
주당**가치**(밸류에이션)와 주당**이익**(EPS, 회계 공시)은 다른 체계:
- 전환가능상품은 원칙 **희석EPS에만** 영향(의무전환상품은 기본EPS에도).
- 반희석 판정: 전환 시 보통주 1주당 세후이자(우선주는 배당)가 계속영업 기본EPS 초과 시 제외.
  **외가격 여부는 희석성 판정과 무관**(옵션·워런트와 다름).
- 복수 전환특성 → 시나리오별 계산 후 **가장 희석적인(최저) 값** 표시. 전환상품 구매옵션은
  3요건 충족 시에만 행사 가정 + TSM 분모 산정.

## 3. SBC의 가치평가 반영 (742·743)
### 계속기업 DCF (다모다란)
- **add-back 금지**: 주식결제형 SBC도 '현물(in-kind)' 실질비용 — 비현금이라고 순이익에
  다시 가산하면 FCF 과대·체계적 과대평가('공짜 점심', malpractice). Tech처럼 SBC 비중 큰
  산업에서 영향 큼.
- **이중 조정**: ①FCF에서 SBC 차감 유지 ②모든 발행 옵션 FV를 지분가치에서 차감(§2) +
  미가득 제한주식은 몰수(forfeiture) 할인 후 주식수 포함.
- 게이트 `check_sbc_treatment(purpose='valuation')`: add-back이면 WARN.

### 손상 사용가치 VIU (IAS 36 — 3해석 대립)
| 해석 | 처리 | 위험 |
|---|---|---|
| 문언적(엄격) | 주식결제형 SBC **제외**(비현금·자금조달·세금 명시 제외 = '현금흐름 순수성') | 경제적 희석 미반영 → VIU 과대 → **손상 은폐** |
| 경제적 비용 | 현금흐름에 **포함** | IAS 36 문언과 충돌 — 회계적 비인정 위험 |
| **할인율 조정(BDO, 권장 경로)** | 현금흐름 제외 + **할인율 상향**으로 희석 반영 + 주석공시 | 정량화 주관성 — 강한 근거 필요 |

- **현금결제형 SBC는 논쟁 없음**: 실제 현금유출 → CGU 배분비용에 항상 포함.
- **이중계산 금지**(할인 일관성 원칙): 같은 위험·비용을 현금흐름과 할인율 양쪽에 반영하면
  overdiscount → 손상 과대. 하나에만.
- 게이트 `check_sbc_treatment(purpose='viu')`: 현금결제형 제외/주식결제형 직접차감/제외+할인율
  미조정 → 각각 WARN, 제외+할인율 조정 → PASS.
- **'이중 언어' 실무**: 법정 손상테스트 = IFRS 엄격 준수, 내부 가치평가·투자판단 = 다모다란식
  경제 조정 — 목적이 다르므로 병행(742/743 결론).

## 4. 우리 플랫폼 (🔨 현행)
- **`dcf.py` 희석 브리지**: `dilutive_claims_value` 분자 차감(기본 0 = 골든 8413.38 불변).
- **게이트**: `check_dilution_bridge`(미반영·TSM WARN) · `check_sbc_treatment`(valuation
  add-back WARN / VIU 3해석 분기). 테스트 6.
- **미구현(보류)**: ESO 전용 Lattice(조기행사 배수·blackout) · 몰수율 반영 제한주식 ·
  VIU 할인율 조정 정량화 도구 · EPS(IAS 33) 계산기 — 수요 발생 시.
