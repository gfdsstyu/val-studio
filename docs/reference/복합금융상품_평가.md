# 복합금융상품 평가 (CB·RCPS·BW) — ⏳ 미래 트랙

> DCF가 아니라 **옵션평가**. 전환·상환·조기상환 등 옵션이 결합된 상품. [[밸류에이션_스코프_로드맵]]의
> 복합금융상품 트랙. 씨앗: 외부평가의견서 taxonomy(롯데케미칼 이항모형·신주인수권 OPM).

## 1. 평가 모형 2계열
| 계열 | 모형 | 가정 | 적합 |
|---|---|---|---|
| **혼합할인율** | GS(Goldman Sachs)·**TF(Tsiveriotis-Fernandes)** | 만기까지 이자율 일정, 이자율 변동성 미반영 | 주식 변동성 큰 **초기기업**(효율적) |
| **이자율 모형** | BDT·Vasicek·Hull-White | 이자율을 확률변수로(시간가치 반영) | **고신용등급** 상품 |

- **TF모형**: 전환사채를 **주식성분/채권성분 분리**해 각각 다른 할인율(채권성분=신용위험 반영, 주식성분=무위험).
  CB·RCPS의 표준.
- **이항모형**: 전환·상환·조기상환 결합을 이산시점 최적행사로. 실무 다수.
- **OPM(Black-Scholes)**: 단순 옵션(신주인수권 등) 폐형해.

## 2. 전환권 분류별 평가 (회계처리 직결)
| | 평가 방식 |
|---|---|
| **전환권 = 자본** | 발행가=공정가치면, **무옵션부채권가치 − 상환권 옵션부채권가치** = 자본요소 규모(잔여법) |
| **전환권 = 부채** | 전환권·상환권의 **상호배타적 속성** 고려 → 두 권리를 **단일 파생부채로 통합 평가** 권장 |

- 후속측정: 주계약은 유효이자율법 상각. 분리 여부에 따라 **만기 상각 vs 기대만기 상각** 결정.
- 내재파생상품: 전환권이 부채일 때 내재파생 분리 평가.

## 3. 공정가치 서열체계 (Level 1/2/3)
관측가능성 우선: **Level 1 > 2 > 3**. 상위 없을 때만 하위.
| 레벨 | 투입변수 | CB/RCPS |
|---|---|---|
| **1** | 활성시장 동일자산 공시가격 | CB 자체는 드묾 |
| **2** | 관측가능(유사상품·수익률곡선·신용스프레드) 전부 시장관측 | 채권가격/다만기 보간 필요 — 드묾 |
| **3** | 관측불가 투입변수 | **대부분의 CB·RCPS·BW** |

- **⭐ 변동성이 레벨을 결정**: 상장사 CB라도 주가·수익률곡선 관측되어도, **변동성을 역사적 주가에서**
  뽑으면 IFRS 1113 B36(2)에 따라 **Level 3**. 대부분 복합금융상품이 Level 3인 이유.

## 4. 특수 이슈 (씨앗)
- 공정가치 ≠ 취득원가(거래가액)일 때 처리 / 수의상환권(Call) 인식 여부 / 만기전 재매입·조기상환 /
  전환사채 유형별 회계처리 순서 — 향후 트랙 착수 시 상세화.

## 5. 우리 플랫폼 (⏳ 미래)
- **별도 계산코어**: DCF 아님 → 이항트리·TF·OPM·몬테카를로. `calc_core`와 분리, 공통백본 재사용.
