# 공정가치 측정 (IFRS 13) — 🔨 Backsolve 코어 검증 완료

> [[밸류에이션_스코프_로드맵]]의 공정가치(FV) 트랙. 원천: IFRS Issue Paper 시리즈
> (217·345·346·347·350·411·412·414·201). 엔진: `calc_core/backsolve.py`(OPM 워터폴+역산),
> 게이트 4종. 복합금융상품의 Level 논점은 [[복합금융상품_평가]] §7과 상호 참조.

## 1. 적용범위 (in-scope 판단이 첫 단계)
IFRS 13은 다른 기준서가 공정가치를 요구/허용할 때 적용되는 **공통 기준서**(문단5).
**Out-scope 3영역**(문단6): 주식기준보상(1102)·리스(1116)·재고 NRV/자산손상 **사용가치**(1002/1036)
— "공정가치와 비슷하나 공정가치가 아닌" 측정치. ∴ [[손상검사_impairment]]의 VIU 는 IFRS 13 밖.
파생 정의 관련: 기초자산이 **계약당사자 특정 비금융변수**(영업이익·EBITDA 등)면 파생·공정가치
측정 대상이 아니다.

## 2. 공정가치 서열체계 — 판정 규칙
| 레벨 | 투입변수 |
|---|---|
| **1** | 측정일 접근가능한 **동일(identical)** 자산·부채의 활성시장 **조정 없는** 공시가격 |
| **2** | 직·간접 관측가능(유사상품·수익률곡선·신용스프레드) |
| **3** | 관측불가능 변수 |

**결정 규칙(결정론 — `check_fv_hierarchy` 승격)**:
- **가장 낮은 수준이 지배**: 수준 = 사용된 변수 중 최저 수준. 개별적으로 유의한 복수 L3 변수는
  효과가 상쇄(offset)돼도 L2로 못 올라간다. (예: 주가 L1 + 역사적 변동성 L3 → 전체 **L3** —
  대부분의 CB·RCPS가 L3인 이유, [[복합금융상품_평가]] §7.)
- **조정 = 강등**: L1 가격에 조정을 가하면 수준이 내려간다. L1 조정은 문단79 (1)~(3)에서만 허용:
  ①대량 유사자산 matrix pricing ②종가가 측정일 공정가치 미대변(마감 후 유의적 사건 —
  after-market 관측정보로 조정 시 **L2**) ③부채·자기지분을 자산 가격으로 측정 시 조정.
- **유의성 판단 3요소**: 자산 특성 대응 / 전체 측정치 내 비중 / 대체가정 가능성.
- **PxQ(문단80)**: 활성시장 단일 포지션 = 공시가격 × 보유수량 = L1. 보유수량이 커도
  **blockage 조정 불허**, 시장 활성화 여부를 보유수량(size)으로 판단하지 않는다.
- **회계단위(Unit of Account)**: 관계·종속지분은 "개별주식(PxQ)" vs "계약전체(경영권프리미엄
  반영 평가)" 선택 논점 — KASB(전체 허용) vs FSS(PxQ 적절) 회신 상충, Global Firm view는 선택 가능.

### 제3자 가격 (브로커·외부평가기관·consensus)
**IFRIC 판단: 수준은 제3자의 '기법'이 아니라 사용된 '변수'로 결정.** 제3자 가격이라고 자동으로
관측가능 변수가 되지 않는다 — 브로커·평가기관은 **Market이 아니다**.
- 동일상품 활성시장 무조정 가격 전달이면 L1, 자체모델·matrix면 변수에 따라 L2/3.
- consensus(다수 원천 평균): 관측가격 기반 아니면 L3, L1·2 변수 내재면 통상 L2.
- broker 호가는 보통 binding offer가 아님; binding이어도 정상거래 표상인지 확인.
- **⭐ L1이 이용가능하면 문단79 예외가 아닌 한 matrix/모델 L2를 쓸 수 없다**
  (`check_market_price_eligibility` 승격 — 활성시장 시가를 두고 DCF 단독 채택 시 근거 요구).

### 프리마켓/애프터마켓·거래량 (414)
- 공정가치의 요건은 **거래량이 아니라 정상거래(orderly/arm's length)** — 거래량 감소가
  공정가치 자격을 자동 박탈하지 않는다(왜곡·강제매각 개입 여부가 관건).
- 단, **"공정가치"와 "Level 1 공정가치"는 구분**: L1은 거래빈도·거래량과 밀접 — 거래량 급감 시
  L1 탈락 가능(L2/3 기법으로).
- 프리·애프터마켓 가격: 유동성 낮고 변동성 커 **단독으로는 공정가치로 보기 어려움이 다수설**
  (실무=정규장 종가 우선, 참고자료 활용). 예외적으로 정상 참여자·대규모 일관 거래·정규장 지속성
  충족 시 인정 가능.
- IFRS 13 vs US GAAP: IFRS는 **가상의 거래(hypothetical transaction)** 전제를 허용해 실제 거래
  없어도 평가 가능(더 유연). US GAAP(ASC 820)은 실제 관측거래 중시.

## 3. day-one 차이와 calibration (347)
거래가격은 최초 공정가치와 "종종 같지만 **간주되지 않는다**". 불일치 4상황: **특수관계자 /
강요된 거래 / 회계단위 불일치 / 비주된시장**.
- 차이 처리(`check_day_one_difference` 승격): **L1·2 → 즉시 당기손익**, **L3 → 이연 후 상각**
  (한국 실무 정액법 다수). 어느 쪽이든 **비금융요소 판단 선행** — 상대방이 주주·종업원·제3자면
  비용·배당·급여 처리 후보(예: 대주주 저가양도 콜옵션 = 손실, [[복합금융상품_평가]] §6).
- **calibration**: 관측불가능 변수 사용 시 거래일과 후속기간 평가방법을 **동일하게** 적용 —
  거래 내재 IRR·거래 내재 배수를 day-1 벤치마크로 잡고 시장 벤치마크 대비 할인·할증률을
  정량화해 후속기간에도 지속 고려.
- **할인·할증 허용 경계**: 자산 특성(경영권프리미엄, 시장성 결여 할인)은 반영 가능.
  **규모(size)에 기인한 blockage·매각제한 할인은 반영 금지**(자산 고유 특성이 아님 — 구 KGAAP
  출자전환 10~20% 감액 관행은 IFRS 부적합).

## 4. Backsolve/OPM — 비상장주식 보통주 공정가치 (201·411·412)
### 언제 쓰나 — Stage 1 판정
AICPA: 매출·비용이력이 거의 없어 신뢰할 현금흐름 예측이 불가능한 기업(**Stage 1**)은
수익접근법(DCF) 부적합 → 최근 우선주 라운드 거래가가 있으면 **Backsolve가 가장 신뢰할 만한
방법**. 플랫폼의 실행순서 게이트와 동형: "현금흐름 예측 불가 → income approach 차단 →
Backsolve 경로 라우팅".

### 핵심 사상
- **보통주 = Call Option**: 기초자산 = 총 지분 FV, 행사가격 = breakpoint(배분권리가 달라지는
  청산가치 임계점). 우선주 청산우선권이 breakpoint 위치를 결정.
- **워터폴 구간 분해**: 구간 [K_lo, K_hi)에서 지분율 s를 받는 클래스의 가치
  = s × (Call(K_lo) − Call(K_hi)). 전 구간 합 = 총 지분 FV(항등식).
- **역산(시행착오법의 결정론화)**: 앵커 클래스(최근 라운드)의 배분가치 == 발행가액이 되는
  총 지분 FV를 이분탐색(배분가치는 FV에 단조증가 — ∂/∂E = N(d1(K_lo))−N(d1(K_hi)) > 0).

### 골든 예제 (두 클래스, 412 — `tests/test_backsolve_fv.py` 재현)
Series A 발행가 1,000,000 / 청산 시 A 우선 1.2M(break 1) → 보통주 1.2M(break 2, 누적 2.4M)
→ 잔여 10:90. OPM: σ80%·r4%·기간 6y·배당0.
```
Equity FV = 1,000,000 + Call(K=1.2M) − 0.1 × Call(K=2.4M)
$5,022,875 = 1,000,000 + 4,430,673 − 0.1 × 4,077,981
```
워터폴 재배열: preferred = E − Call(1.2M) + 0.1·Call(2.4M) = 1,000,000 ✓ (엔진 재현 오차 <$1).

### 한계·전제 (게이트 승격)
- **전제 = "거래가액 = 공정가액"**: Arm's Length 아니거나(특수관계·전략적 프리미엄)
  평가일과 시점 괴리 시 조정 필요(`check_backsolve_anchor` — 미확인은 통과 금지).
- **IFRS와의 긴장**: Backsolve는 즉시반영, IFRS Level 3은 거래가-공정가 차이 이연상각 —
  Level 3 적정성 검토 + DCF·CCA 교차검증 + 이연상각 조정으로 정합화.
- **RCPS/CPS 포함 자본구조**: 청산 vs 전환 선택으로 **행사가격이 노드별 변동** —
  BSM 폐형 부적합, 이항/몬테카를로 필요(예: Exit $1.5B에서 주당 $83이면 청산우선권 행사,
  $3B에서 $167이면 전환). 미구현, 명시적 보류.
