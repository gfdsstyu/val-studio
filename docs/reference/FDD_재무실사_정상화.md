# 재무실사(FDD) — QOE·NWC·정상화

> FDD(Financial Due Diligence): M&A·투자 전 대상회사 재무를 검증하고 **정상화**해 평가·가격의 기초를
> 만든다. DCF 입력(EBITDA·NWC)의 신뢰성을 담보하는 상류 공정. [[모델링_실무_2강4강]]·감사인 트랙과 연결.

## 1. 정상화 (Normalization) — 왜·무엇을
관측된 실적을 **반복가능·소유주변동 무관한 정상 수준**으로 조정. M&A·투자유치·공정가치 평가의 객관 기준.
조정 대상:
- 일회성(비반복) 손익, 특수관계자 거래(비시장가격), 회계오류·미보고 항목,
- 소유주 개인비용, 배분 왜곡, 지속불가 항목.

## 2. QOE (이익의 질, Quality of Earnings)
> **정상 영업활동에서 반복가능성 높고, 소유주 변동에도 유지가능성 높을수록 이익의 질이 높다.**

분석 영역:
| 영역 | 점검 |
|---|---|
| **매출 질** | 시장점유·경쟁지위, **고객집중도·이탈위험**, 단가/수량 동학, 수주잔고(backlog), 계절성 |
| **원가구조** | 공급처 의존·원자재 변동, **고정비 vs 변동비** 구성, 제품별 GP 일관성 |
| **판관비** | 인력 적정성·핵심인력 위험, 보상 벤치마킹, 지속가능 복리후생 |
| **세무** | 과거 신고 정확성(추징 위험), 우발 세부채, 진행 분쟁 |

→ **normalized EBITDA** 도출: 반복가능 이익 vs 이상치 구분. 이게 밸류에이션·배수의 기초.

## 3. NWC (순운전자본) 실사
> **순운전자본 = 영업활동에 필요한 유동자산 − 유동부채.** 영업에 묶인 자본.

### 4대 구성
1. **현금**: 최소영업현금 vs 잉여현금 구분(잉여=비영업자산).
2. **재고**: 진부재고, 회전율(원가 대비 일수), 안전재고. 단가 변동.
3. **매출채권**: 회수정책, 연령분석(정상초과), 팩토링(우발부채 유발).
4. **매입채무**: 결제조건, 회전율(동종 대비).

### Target NWC (peg) & 가격조정
- **Pro forma NWC**: 미보고 오류·지속불가·특수관계·배분이상 조정 → 정상 운전자본 수준.
- **NWC peg(target)** = 정상 NWC 기준선. 거래 종결 시 실제 NWC가 peg 대비:
  - 초과 → 매도자에게 추가 지급 / 미달 → 거래가격 차감. (**price adjustment 메커니즘**)

## 4. 우리 플랫폼 반영
- **정상화 레이어**([[파서_아키텍처_매트릭스]]의 _A/_F 조정과 연결): 실사조정을 입력에 반영.
- normalized EBITDA·NWC가 DCF 입력의 신뢰 기초. QOE 조정항목을 provenance로 추적.
- 감사인 트랙: 취득 후 실적 vs 취득시 추정 비교(손상·과대취득 점검, polaris 감리사례).
