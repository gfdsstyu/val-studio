# 모델감사 분석적 절차 — 시계열 연속성 기반 결함 탐지 (귀납지식)

**출처**: 실제 DCF 모델(연수 산출물) 전 시트 수식 전수 추적 리뷰 실측 (2026-07). 원 조서는
비공개 원자료 — 본 문서는 재현 가능한 패턴·임계값만 증류.
**구현**: `calc_core/analytical.py`(L3 검사 6종) · `excel/model_audit.py`(정적 감사 3종) ·
`/api/review/analytical` · `/api/xlsx/audit`. 계획 문서: `docs/plan/analytical_review_workflow.md`.

## 1. 핵심 명제 — 항등식은 잘못된 비율로도 성립한다

리뷰 실측에서 결함 8건 중 5건(참조 밀림 계열 전부)은 tie-out(합계·정합 검산)으로 잡히지
않았다. 원가율 자체가 틀리면 `영업이익 = 매출 × (1−원가율−판관비율)` 항등식은 통과한다.
이 계열을 잡은 유일한 절차는 **"비율을 실적→추정 시계열로 늘어놓고 튀는 지점의 분모·분자를
쪼개 역추적"** — 감사기준의 분석적 절차(ISA 520: 기대치 형성→차이 식별→원인 조사)와 동형.

검증은 3층이 상호 보완한다 (어느 층도 다른 층을 대체 못 함):

| 층 | 질문 | 잡는 결함 |
|---|---|---|
| L1 tie-out | 데이터가 원본과 일치하나 | 전기·오타 |
| L2 가정 게이트 | 가정이 경제적으로 말이 되나 | PGR≥WACC, TV 비중 과다 |
| L3 분석적 절차 | 시계열이 과거·구성요소와 정합하나 | **참조 밀림·배분 중복·드라이버 오배선** |

## 2. 결함의 3계열 병리와 대응 탐지기

| 계열 | 병리 | 표면화 형태 | 탐지기 |
|---|---|---|---|
| ① 참조 밀림 | 수식을 옆·아래로 복사하며 시작 참조 미고정 | 이웃 패턴을 깨는 수식 / 비율 V자 스파이크 | 패턴 린트 + spike_revert |
| ② 경로 중복 | 값이 흐르는 경로가 하나로 안 정해짐(SSOT 위반) | 배분율 합 ≠ 100%, 총액 불일치 | tie-out + 잔차 배분 강제 |
| ③ 연산자 오류 | 실적 열과 추정 열의 수식 구조 상이 | 곱 자리에 SUM 등 — 값은 그럴듯해 육안 미탐 | 패턴 린트(구조 대조) |

## 3. V자 시그니처 — "오류 vs 가정" 구분 휴리스틱

**사업 이벤트는 지속되고(레벨 시프트), 참조 오류는 한 해만 튄다.**
비율이 한 해만 이탈 후 트렌드로 복귀하면(이웃끼리는 일치) 참조 밀림 시그니처다.

```
판정: |x[i] − (x[i−1]+x[i+1])/2| > 2%p  AND  |x[i+1] − x[i−1]| < 1.5%p
```
실측 근거: 결함 연도 이탈 +2.99%p·이웃차 1.13%p (포착) / 레벨 시프트는 이웃차가
이탈만큼 커서 배제. 복귀 없는 점프(지속되는 전환)는 이 검사에 안 걸린다 — 그건 가정일
수 있으므로 접합부 검사(±3%p)가 "근거 요구" 수준으로만 지적한다. **두 검사의 역할
분담 자체가 판정 프레임**: V자=실행 오류 의심, 지속 점프=판단(근거 기재 요구).

## 4. 임계값과 실측 근거 (전부 WARN-only — 재검토 신호)

| 검사 | 임계 | 실측 근거 |
|---|---|---|
| 접합부(실적말↔추정초) 비율 | ±3%p | 결함 이탈 +6.6%p(2배 초과) / 정상 연결 −1.3%p(절반) |
| 회전기일 접합부 | 상대 ±20% | 재고 회전 130~225일 변동성 감안 |
| V자 스파이크 | 이탈 2%p·이웃차 1.5%p | §3 |
| 파생지표(인당 인건비 등) YoY | ±10% | 결함 +40%(배분 중복) — 분자·분모 각각은 정상으로 보임 |
| 컨센서스 괴리 | ±5%p | 실측 괴리 6.8%p — 같은 파일 안에 있었는데 미대조 |
| 성장-운전자본 | 매출 YoY>10% 인데 \|ΔNWC\|<Δ매출×2% | 매출 +33.5% 성장에 ΔNWC=0 (운전자산 전액 누락) |
| 민감도 중심셀 | 본계산과 ±0.01 | 표시값 +2.6% 과대 오독·민감도 폭 절반 축소 표시 |

## 5. 수식 패턴 린트 (R1C1 정규화) — 레이아웃 지식 불요

A1 참조를 호스트 셀 기준 상대 오프셋(R1C1)으로 정규화하면, 같은 패턴으로 복사된 수식은
호스트가 달라도 동일해진다. 행/열 연속 수식 구간(≥3셀)에서 과반 패턴과 다른 셀 = 참조
밀림/구조 이탈 후보. ①계열(단독 오참조·열 밀림)과 ③계열(연산자 상이)을 커버한다.

**한계(계층 분담)**: 행 전체가 **균일하게** 밀린 경우(전 열이 같은 폭으로 오참조 —
이웃도 같이 틀림)는 이웃 대조로 못 잡는다. 그 유형은 L3 시계열 검사(추정 첫해 ΔNWC=0
등 결과값 이상)가 담당한다. 정적 린트와 분석적 절차는 보완재다.

## 6. 파생지표 검산 — "각 셀은 맞는데 결합하면 틀리는" 유형

배분 중복(동일 모집단을 두 계정이 각각 100% 사용)은 셀 단위로는 전부 정상으로 보인다.
`인당 인건비 = (원가 노무비+판관 인건비)/인원` 같은 **파생지표의 YoY**로만 드러난다
(실측: 전년 ±10% 검산 한 줄이 있었다면 +40% 급등이 즉시 표면화). 예방책은 잔차 배분
(총액 먼저 확정 → 한쪽은 총액−다른쪽)으로 합보존을 수식 구조가 강제하게 하는 것.

## 7. 민감도 중심셀 검산 — 비용 대비 효과 최대

민감도 그리드는 홀수 격자·중심=base 로 만들고 `중심셀 ≟ 본계산` 검산 한 줄을 단다.
① 축이 입력셀을 참조하는 순환(재계산해도 안 고쳐짐 — stale 과 증상 동일하나 원인 상이)
② stale 테이블 ③ 축 설정 오류 ④ 연결 끊김이 이 하나로 동시에 잡힌다. 실측에서 서로
다른 두 결함(진본 축 순환 / 사본 stale)이 같은 검사로 적발되었다.

## 8. 검산 장치와 결함의 상관 (실측)

검산 행(TRUE/FALSE 교차합계)이 처음부터 있던 시트에서는 결함 0건, 없던 시트들에서
전 결함이 나왔다. 결함은 개별 실수가 아니라 **작업 방식의 계통 결함**이므로 처방도
장치로 수렴한다: 허용오차 비교(정확일치는 부동소수 오작동) + **불일치 시 TRUE/FALSE 가
아니라 잔차 금액 표시**(원인 추적 즉시 가능). 오류 수정 시에는 **한 건씩 적용하고 매번
재계산해 영향을 분리 기록**할 것 — 반대 방향 오류들이 상쇄로 서로를 가린다(실측: 개별
−111/+26 이 순 −3.0%에 은폐).

## 9. 판정 프레임 — 방법론 vs 실행

리뷰 결론은 4층으로 가른다: 방법론 선택(표준 여부) / 구조 설계(잔차 배분·SSOT) /
실행(참조·합산) / 검산 장치(유무). **방법론 오류는 학습으로, 실행 오류는 검산 장치로**
해결된다 — 처방이 완전히 다르므로 이 구분이 리뷰 리포트의 첫 문장이어야 한다.
(구현: Finding.detail["layer"] 태그 → 리포트 계층 집계.)
