# 운전자본 벤치마크 (회전기일 분포)

> 자동생성(`scripts/build_wc_benchmarks.py`) — 파싱표에서 회전기일 역산(최근 실적연도). n=81편. rigor=학회리포트(참고).
> ⚠️ **caveat**: 산업별은 대부분 n=1(큐레이션∩WC파싱 얇음) — 큐레이션 확대 시 두꺼워짐. 극단값(DSO<2 또는 >200일: HD현대미포 1일·코오롱 258일 등)은 표 파서 컬럼 오정렬 artifact 가능성 → [[감사스캔_리포트]]로 교차검증 후 신뢰. 전체 중앙값(DSO~51·DIO~103·DPO~45)은 견고.
