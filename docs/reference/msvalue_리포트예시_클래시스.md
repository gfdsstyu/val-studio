## 2. 5.주요가정 (Key Assumptions) — Assumption 스키마 정본

| 항목 | 내용 |
|---|---|
| **추정기간** | 2024-01-01 ~ 2028-12-31 (5년). 사업 현금흐름 고려. |
| **매출액** | 구분: 제품/임대/기타. 제품매출 세부: 의료기기(**장비/소모품**), 화장품(**내수/수출**). 장비=글로벌·국내 미용기기·뷰티 시장 전망치 준용(top-down). 소모품=**장비 누적매출 연동**(razor-and-blades). |
| **매출원가** | 제품/임대 구분. 제품원가 세부: **재료비·노무비·기타경비·상각비**. 재료비=매출액 대비 비율. 노무비=급여·퇴직급여·복리후생, **예상명목임금상승률+급여대비비중**. |
| **판매관리비** | 인건비·변동비·경상연구비·고정비·상각비. 인건비=명목임금상승률+급여비중. 변동비(세금과공과·운반비·광고선전비·판매수수료)=매출대비비율. |
| **상각비** | 평가기준일 보유자산 상각 스케줄 + 추정 CAPEX. |
| **CAPEX** | 현 보유자산 **상각비 수준의 재투자** + 해외진출 투자 반영. |
| **WC** | 매출채권·재고자산·매입채무·선수금·기타운전부채. **과거 2개년 평균기일 또는 최근연도 회전율**. |
| **WACC** | 유사회사 6개(미용 의료기기). Ke=국내 무위험이자율+시장위험프리미엄+**2년 주간 조정베타**. Kd=평가대상 신용상태 회사채 이자율. 목표자본구조=유사회사 평균. |
| **PGR(영구성장률)** | **1%** |
| **Net Debt** | 비영업자산=현금성자산·장단기금융상품·투자부동산. 이자부부채=장단기차입금·장단기리스부채. |

> 이 서술이 우리 `models.py` Assumption + `fs_mapper` NOA/IBD + `revenue` 트리(장비>소모품, 화장품>내수/수출)의 **정본**. 매출추정 §"소모품=장비 누적매출 연동"은 revenue.py 확장 포인트.

## 3. 7.DCF — 3-시나리오 + 결과 (base case)

| 결과(base) | 값 |
|---|---|
| 지분가치(100%) A | 2,368,000 백만원 |
| 주식선택권 예상납입자본 B | 13,420 |
| 조정 지분가치 C=A+B | 2,381,000 |
| 희석주식수 D | 65,461,702 |
| **주당가치 E=C/D** | **36,380 원** |
| 영업가치(=ΣPV FCFF + PV terminal) | 2,284,000 |
| 비영업자산 / 이자부부채 | 149,900 / 65,630 |

**FCFF 로직**(FY24~28 + Normalized): 매출→매출원가(원가율~22.6%)→매출총이익(GP% **77.4%**)→판관비(~21.8%)→영업이익(EBIT% **51~56%**)→법인세→세후영업이익→+감가상각 −CAPEX −운전자본변동 → **FCFF**. 현가계수 mid-year(0.9505, 0.8588, …). Terminal=Normalized FCFF/(WACC−g).

**민감도표**: 할인율 {9.68%, 10.68%, 11.68%} × PGR {0%, 1%, 2%}. base 중심 = 할인율 10.68% × PGR 1% → 2,368,000.

**3-시나리오**: base 36,380원 / upside 37,400원 / downside(동일 표기, 매출성장률 가정 차이). → 우리 `6.시나리오` + 민감도 설계 참조.

> 비올 대비: GP% 77.4%(비올 ~77%)·EBIT% 51~56%(비올 ~52%) 거의 동일 = 동종업종 마진 확증. PGR 1%(비올 2%), WACC 10.68%(비올 11.3%).

## A. 매출 세분화 트리 (10.매출 상세) — `revenue.RevenueNode` 정본

```
제품매출
├─ 의료기기 장비
│   ├─ 클래시스_수출   성장률 30.0/36.3/30.0/23.7%  (가정·근거, 장비매출 72~78%)
│   ├─ 클래시스_내수   성장률 17.3% flat
│   ├─ 클루덤_수출     성장률 11.4% flat
│   └─ 클루덤_내수     성장률 2.8% flat
├─ 소모품  ← 장비 누적판매 연동(razor-and-blades)
│   ├─ 수출            성장률 ~32% (32.4/38.5/32.5/26.3%)
│   └─ 내수            성장률 ~22% (22.2/22.0/21.8/21.7%)
└─ 화장품 (스케덤/슈링크RX)
    ├─ 수출            성장률 5.2% flat (화장품 시장전망률)
    └─ 내수            성장률 4.0% flat
```
- 축: **제품군 > 브랜드 > 내수/수출** (지역이 최하위축). 브랜드별·채널별 성장률 개별 가정.
- 장비는 시장 전망치(top-down) 준용, 소모품은 장비 설치기반 누적 연동, 화장품은 시장성장률.
- → `RevenueNode` 리프에 `growth` 경로 세팅; 소모품 누적연동은 `revenue.py` 확장 훅.
