# 밸류에이션 기법 선택 로직

같은 4대 드라이버(매출·마진·CAPEX·WC)로 현금흐름을 세워도, **최종 가치를 뽑는 기법**은
사업 성격이 결정한다. SMIC 182편의 `valuation_method` 빈도(→ [[벤치마크_분포]])와 리포트가
명시한 선택 근거를 귀납한 결정 트리.

> 코퍼스 빈도: 상대가치(멀티플) 압도, DCF 소수, SOTP·rNPV 특수. 학회 특성(예측 부담↓·상대가치
> 선호)이나, **기법 선택 자체가 사업 이해의 표현**.

## 선택 결정 트리

| 기법 | 언제 (사업 성격) | SMIC 실례 |
|---|---|---|
| **DCF** | 현금흐름 예측 가능 + 고성장(멀티플로 성장 미반영) | [[smic/Tempus-AI_20251\|Tempus]]·[[smic/Fluence_Energy_Inc_20241\|Fluence]]·[[smic/HD현대마린솔루션_20261\|HD현대마린]] |
| **SOTP** | 부문 이질(성장·마진·시황 다름)·지주 | [[smic/케이씨_20241\|케이씨]]·[[smic/AlibabaGroup_20191116\|Alibaba]]·[[smic/한화솔루션_20251\|한화솔루션]] |
| **PER (상대가치)** | 안정적 이익·성숙·peer 풍부 | [[smic/오리온_20241\|오리온]]·[[smic/하이브_20252\|하이브]]·[[smic/에이피알_20241\|에이피알]] |
| **PBR (상대가치)** | 자본집약·사이클·순자산 중요 | [[smic/한화오션_20241\|한화오션]]·[[smic/SK하이닉스_20232\|SK하이닉스]]·[[smic/TSMC_20221\|TSMC]] |
| **rNPV** | 파이프라인 바이오(성공확률·미래 현금) | [[smic/알테오젠_20241\|알테오젠]] |
| **자산가치/NAV** | 부동산·지주·투자자산 | (부동산개발·지주 후보) |

## 근거 로직 (리포트 명시)
- **DCF**: "고성장이라 멀티플이 성장을 못 담음" (Tempus "Why DCF"), 반복매출 가시성(HD현대마린 LTSA).
- **SOTP**: "부문 이질로 통합 배수 부적합 → 사업부별 peer 배수" (케이씨 5개 자회사, Alibaba
  커머스/클라우드/미디어). → [[리포트예시_클래시스]] SOTP 양식.
- **PER**: "DCF 부적합 → Peer PER Method" (에이피알 명시). 안정 이익·peer 풍부.
- **PBR**: 자본집약(조선·파운드리)·사이클(메모리)로 이익 변동성↑ → **순자산 기준**이 안정적.
  사이클 저점 PBR 매수 논리(SK하이닉스).
- **rNPV**: 상장 전·파이프라인 바이오는 이익 없음 → 성공확률 가중 미래 현금(알테오젠).

## 교차 관찰
1. **기법은 "현금흐름 예측가능성 × 자산성격"의 함수** — 예측가능+성장 = DCF, 예측난+자본집약 =
   PBR, 안정이익 = PER, 이질부문 = SOTP.
2. **rigor 주의**: 학회는 상대가치 편향(예측 부담↓). 골든(비올·클래시스·[[모델러스_통합모델_5.4]])은
   DCF 정본. 기법 선택 근거의 명시 여부가 리포트 품질 신호.
3. **기법 ≠ 배수 값**: 기법 선택 후 배수·할인율은 [[벤치마크_분포]]·[[감사인검토_WACC방법론]]로.

## 활용
- 플랫폼: 신규 기업 → 사업 성격(예측가능성·자본집약·부문이질·파이프라인) → 기법 라우팅.
- 기법 선택 근거 미명시 = 감사 트랙 red flag.
