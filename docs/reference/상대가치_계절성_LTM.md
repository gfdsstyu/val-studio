# 상대가치법 — 계절성 유사회사 처리와 LTM 보정 (분·반기 평가)

> 출처: polaris 블로그(2025-07). 상대가치 트랙(⏳향후 구현)의 첫 챕터 — **peer 선정
> ([[리포트예시_클래시스]] §E 4-step)의 '유사성' 개념을 재무 패턴(계절성)까지
> 확장**하는 실무 규칙.

## 1. 문제: 분기 실적 연환산의 계절성 왜곡
분기 평가에서 관행적으로 `1분기 실적 × 4`로 연환산하지만, 이는 **실적이 고르게
발생하는 기업 전제**. 4분기 집중형(예: 유통업 연말 소비) 유사회사에 적용하면:

실측 예시 — 분기 매출 100/120/130/350억(연 700억)인 A사:
| 연환산 방식 | 결과 | 왜곡 |
|---|--:|---|
| 1분기 × 4 | 400억 | 연 700억 대비 **-300억 과소** |
| 4분기 × 4 | 1,400억 | **2배 과대** |

멀티플 분모가 왜곡되면 평가대상 공정가치 산정이 통째로 틀어진다.

## 2. 원칙: 계절성이 다르면 제외
**유사회사는 재무·사업 특성이 실질적으로 유사해야** 하며, 계절성 패턴이 평가대상과
다르면 **집단에서 제외하는 것이 원칙**. → peer 선정 4-step 의 유사성 판단(Step2)에
사업 내용뿐 아니라 **분기 실적 패턴(계절성)** 관점 포함.

## 3. 불가피하게 포함 시: LTM 보정
**LTM(Last Twelve Months) = 최근 4개 분기 누적** — 연환산 대신 직전 12개월 실측 사용.

계산 예시(기준일 X2년 1분기 말): LTM = X1Q2 120 + X1Q3 130 + X1Q4 350 + X2Q1 120
= **720억** → EV/EBITDA·PSR 등 멀티플 분모로 사용.

- 계절성이 아닌 **일회성 요인**(손상·소송비 등)이면 LTM 이 아니라 **normalization**
  (일회성 제거 — [[FDD_재무실사_정상화]] QOE 와 동일 개념) 적용.

## 4. 보고서 기재 의무 (정형 문구 3종)
투명성 요건 — 보고서에 반드시: ①계절성 보정 **필요성**("유사회사 일부가 4분기 매출
집중 특성…과소·과대 추정 가능성") ②보정 **방법**("계절성 큰 유사회사는 LTM 누적
실적 기준으로 멀티플 산정") ③적용 **내역**("유사회사 A·B 는 연매출 40% 이상이
4분기 집중 → 1분기×4 대신 LTM 적용"). 유사회사 선정 기준·한계점 명기.

## 우리 플랫폼 매핑
- **peer_selection 확장 후보(상대가치 트랙 구현 시)**: PeerCandidate 에 분기 매출
  패턴 → 계절성 지표(예: 최대분기 비중 ≥40% flag) → Step2 판정 관점 추가 또는
  별도 결정론 필터. 애매하면 uncertain(유저 결정 큐) — LLM 판단보조 원칙.
- **LTM 계산기**: 분기 XBRL(research_brief ⑩이 이미 분기·전기 fact 수집)에서 최근
  4개 분기 합산 — 결정론 유틸로 구현 가능.
- 보고서 정형 문구 3종 = 리포트 생성(5단계) 슬롯 템플릿.
