# M&A 구조화·합병 규제가액·세무 — Structuring 정본

> 출처: 중소벤처기업부·S사회계법인 「M&A ESSENCE」(2020) 제5~6장.
> [[합병_주식교환_방법론]](두산 기준주가·본질가치)의 **법제·세무 확장** — 거래구조
> 선택이 절차·세금·평가방법을 동시에 결정한다.

## 1. 구조 4유형 + 선택 기준

| 구조 | 절차 핵심 | 세무 핵심 |
|---|---|---|
| 자산양수도 | 개별 자산 매매 준용(비상장은 법정절차 최소) | 양도차익 법인세·취득세, 부당행위계산부인(시가±5% 또는 3억) |
| 영업양수도 | 주총 특별결의·주식매수청구(중요 시), 등기·채권자보호 불요 | 포괄 양수도면 부가세 면제·중고자산 내용연수 50% 신고 가능 |
| 합병 | 주총·매수청구·채권자보호(+상장이면 외부평가·공시) | 적격 여부가 좌우(§4) |
| 분할·주식교환 | 포괄 이전(분할 §·교환 [[합병_주식교환_방법론]]) | 적격분할 유사 체계 |

- **영업양수도 vs 물적분할 후 지분매각**(최근 영업양수도 선호 추세): 전자는 공시·주총
  생략 여지 + **간주취득세 없음**, 후자는 절차 이중(분할+매각)·채권자보호·간주취득세
  발생하나 종결은 지분매각-현금수취로 간편. Carve-out 재무제표 기준 정산(운전자본
  또는 순자산) 필요 — [[MnA_실사_가격구조_SPA]] §7.
- 상장법인 추가 규제: 주요사항보고서·**외부평가기관 평가의무**·종료보고서·우회상장
  제한·주된 영업 양도 시 상장폐지.

## 2. 합병 4유형 (상법 간소화 사다리)
일반합병(주총 특별결의+매수청구) → **소규모합병**(신주가 존속회사 발행주식의 10%
이하·교부금이 순자산 5% 이하 → 존속회사 주총 생략+매수청구권 無) → **간이합병**
(소멸회사 주주 전원동의 또는 존속회사가 90% 이상 보유 → 소멸회사 주총 생략, 매수
청구권은 有) → **삼각합병**(합병대가로 모회사 신주 교부 — 모회사는 주총·매수청구
의무 없이 한정책임).

## 3. 합병가액 법제 ⭐ (자본시장법 — 평가 엔진의 규제 앵커)

| 조합 | 산정 |
|---|---|
| 상장 ↔ 상장 | **기준시가**(이사회결의일·계약체결일 중 앞선 날 전일 기산 1개월 거래량가중평균·1주일 가중평균·최근일 종가의 산술평균) 기준 **±30% 할인·할증 범위**(계열사 간 10%) |
| 상장 ↔ 비상장 | 상장측=기준시가 준용(산출가액이 자산가치 미달 시 자산가치 가능), 비상장측=**본질가치 = 자산가치×0.4 + 수익가치×0.6** + 상대가치 비교 공시 |

- 본질가치 0.4:0.6 = 자산 1 : 수익 1.5 — 우리 `calc_core/merger.intrinsic_value`
  비율과 동일(교차검증 ✓). 수익가치는 DCF·배당할인·이익할인 등 "일반적으로 공정·
  타당한 모형" 허용 → **우리 DCF 주당가치가 수익가치 슬롯에 투입**.
- 기준시가 대비 10% 초과 할인·할증 시 외부평가 필요.
- **주식매수청구권 가격**: 협의 불성립 시 상장 = 이사회결의일 전일 기준 과거 2개월·
  1개월·1주 산술평균(기준주가와 다른 기간 세트!), 비상장 = 합병가액·순자산·상증세법
  가액 등 다양. 매수청구 부담이 합병 무산의 최다 원인 — 합리적 비율 산정 + 행사규모
  예측이 필수.
- 상장-비상장 합병 시 비상장대법인 요건(자산·자본금·매출 중 2개 이상 크면)·우회상장
  요건·최대주주 매각제한.

## 4. 적격합병 — 과세이연의 관문 ⭐

| 주체 | 비적격(일반) | 적격 |
|---|---|---|
| 피합병법인 | 양도차익 법인세·증권거래세 | 양도차익 없음·증권거래세 비과세 |
| 합병법인 | 합병매수차손익 인식·시가 승계·취득세 | 미인식·**장부가 승계(과세이연)**·취득세 50% 감면·자산조정계정 |
| 피합병 주주 | 의제배당 과세 | (이연) |

**요건 5**: ①사업목적(1년 이상 사업 법인 간) ②지분의 연속성 — 합병대가 중 **주식
80% 이상**(2년 내 취득 포합주식은 금전 간주 규정)·지배주주 배정·**사업연도 말까지
1/2 이상 보유** ③사업의 계속성(승계 고정자산 1/2 이상 처분 금지) ④고용승계(근로자
**80% 이상** 승계·유지). **완전자회사(100%) 합병은 요건 없이 과세특례** — 요건
충족이 어려우면 100% 자회사화 후 합병이 대안.

합병 전 단계 최대 세무이슈 = **합병비율의 적정성**: 불공정 비율 → 부당행위계산부인
(법인세)·불공정합병 증여세(상증세법 38조). 상장 포함 합병은 자본시장법 비율이면 세법
인정, 비상장 간은 세법상 시가(특수관계자 간은 통상 상증세법 보충적 평가). ⚠️ 세법상
시가 적용이 상법·형법 리스크까지 제거하지는 않음.

## 5. 주식 양도 세무 (매도자 관점 요점)
- 상장: 장내 대주주만 과세(지분 1%↑ 또는 시총 기준), 장외는 전원 과세. 비상장: 전원 과세.
- 세율: 중소기업 대주주 20%(3억 초과 25%)·소액 10%, 비중소 대주주 1년 미만 30%.
  (+주민세 10%). 부동산 과다법인 특칙.
- **부당행위계산부인**: 특수관계인과 시가 대비 차액 3억 이상 또는 시가 5% 이상
  고저가 거래 → 시가로 재계산 과세(+저가양수 증여세) — **평가보고서의 시가 산정이
  세무 방어의 출발점**(우리 플랫폼 산출물의 실사용처).

## 우리 플랫폼 매핑
- **승격 후보(merger.py)**: 합병가액 할인·할증 밴드 검사 — 제시가가 기준시가 ±30%
  (계열 10%) 이탈 시 FAIL, 10% 초과 할인·할증 시 "외부평가 필요" WARN. 본질가치
  0.4/0.6 가중은 구현·검증 완료.
- 주식매수청구권 가격 계산기(2M·1M·1W 산술평균 — 기준주가와 다른 기간 세트) 후보.
- 거래유형 → 평가·절차·세무 요건 매핑 = 리포트 템플릿의 "거래개요" 자동 선택 로직
  ([[외부평가의견서_고정양식_구조]] 방법론 taxonomy 와 연결).
- 적격합병 요건 5 = 구조화 자문 체크리스트(LLM 판단 + 유저 확인 — 세무는 전문가
  검토 필수 고지).
